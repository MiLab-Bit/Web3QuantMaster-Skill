## 1. LUNA/UST 崩盘 2022.05

### 事件经过
- **时间**：2022 年 5 月 7 日 ～ 5 月 12 日
- **直接原因**：巨鲸大量抛售 UST，脱锚至 0.985，市场恐慌 → 大量铸烧 LUNA → LUNA 恶性通胀 → 死亡螺旋
- **结果**：UST 归零，LUNA 从 $80 跌至 $0.0001，市值蒸发 ~$400 亿

### 量化特征
| 指标 | 数值 |
|------|------|
| LUNA 最高价（崩盘前） | $119.18（2022.04.05） |
| LUNA 崩盘后最低 | < $0.0001 |
| UST 脱锚最低 | $0.35 |
| 崩盘持续时间 | ~5 天 |
| Anchor APY 崩盘前 | 19.5%（不可持续） |
| LUNA 流通供应量（崩盘后） | 6.5 万亿枚（通胀 ~600 万倍） |

### 市场数据（Binance）
```
LUNA/USDT 日线：
  2022-05-01: $85.12
  2022-05-07: $78.34  ← UST 首次脱锚
  2022-05-09: $42.18  ← 市场恐慌开始
  2022-05-10: $18.25
  2022-05-11: $3.41
  2022-05-12: $0.0001  ← 基本归零
```

### 对量化策略的启示
1. **算法稳定币 = 结构性做空机会**：Anchor 20% APY 不可持续，任何做空 UST/LUNA 的策略在崩盘前就有信号
2. **死亡螺旋的量化特征**：UST 脱锚 + LUNA 加速增发 → 正反馈 loop，任何多头策略必须设硬止损
3. **相关性突变**：崩盘期间 BTC/ETH 与 LUNA 相关性从 ~0.3 飙升至 ~0.85（系统风险蔓延）
4. **回测启示**：任何回测如未经 LUNA 归零事件测试，都是无效的

### 可被量化的预警信号
```python
# UST 脱锚预警（可在崩盘前 12-24h 检测到）
def ust_depeg_signal(ust_price, threshold=0.98):
    return ust_price < threshold

# LUNA 增发加速预警
def luna_inflation_signal(luna_supply_history, window=6):
    recent_supply = luna_supply_history[-window:]
    supply_growth = (recent_supply[-1] - recent_supply[0]) / recent_supply[0]
    return supply_growth > 10.0  # 6小时内供应量增长 > 1000%
```

## 2. 3AC（三箭资本）破产 2022.06

### 事件经过
- **时间**：2022 年 6 月 13 日～7 月
- **直接原因**：LUNA 崩盘导致 3AC 巨额亏损，高杠杆 GBTC 套利策略失效，流动性枯竭
- **结果**：3AC 破产，欠债 ~$35 亿，引发行业连锁反应（Voyager、BlockFi 等）

### 量化特征
| 指标 | 数值 |
|------|------|
| 3AC 管理资产峰值 | ~$180 亿 |
| LUNA 崩盘损失 | ~$200 亿（含杠杆） |
| GBTC 折价峰值 | -30%（2022.06） |
| BTC 跌幅（2022.06） | -37%（当月） |
| 穿仓清算量（2022.06.13-19） | ~$12 亿 |

### 对量化策略的启示
1. **高杠杆 + 低流动性 = 死亡组合**：3AC 杠杆率达 3-5x，且大量仓位在 LUNA 上
2. **GBTC 套利策略的风险**：GBTC 折价扩大时，套利策略会巨亏（正基差变成负基差）
3. **穿仓瀑布效应**：大户强平 → 价格下跌 → 更多人强平 → 正反馈

### 可被量化的预警信号
```python
# 大户清算预警（基于公开持仓数据）
def liquidation_cascade_warning(open_interest, price_drop_1h):
    # OI 异常高 + 价格急跌 = 清算在即
    oi_percentile = percentile(OI_30d, open_interest)
    if oi_percentile > 0.95 and price_drop_1h < -0.05:
        return "HIGH_LIQUIDATION_RISK"
    return "NORMAL"
```

## 3. FTX 暴雷 2022.11

### 事件经过
- **时间**：2022 年 11 月 2 日（CoinDesk 曝光 Alameda 资产负债表）～ 11 月 9 日（申请破产）
- **直接原因**：Alameda 持有大量非流动性 FTT 代币作为资产，CoinDesk 曝光后 CZ 宣布卖出 FTT，挤兑 FTX
- **结果**：FTX 破产，客户资金损失 ~$80 亿，FTT 从 $25 跌至 $1

### 量化特征
| 指标 | 数值 |
|------|------|
| FTT 最高价 | $84.17（2021.09） |
| FTT 暴雷前 | ~$25 |
| FTT 暴雷后最低 | $1.01 |
| BTC 跌幅（2022.11.06-09） | -23% |
| ETH 跌幅（同期） | -28% |
| FTX 提现暂停时间 | 2022.11.08 |

### 市场数据（Binance）
```
FTT/USDT 小时线：
  2022-11-02: $25.41  ← CoinDesk 曝光
  2022-11-06: $22.13  ← CZ 推特宣布卖 FTT
  2022-11-07: $16.87
  2022-11-08: $5.23   ← 提现暂停
  2022-11-09: $2.14   ← 申请破产
  2022-11-10: $1.01
```

### 对量化策略的启示
1. **交易所代币 = 极高的交易对手风险**：任何持有大量平台币的交易所都有类似风险
2. **链上挤兑信号可量化**：FTX 暴雷前 48h，链上观测到大量稳定币从 FTX 转出
3. **暂停提现 = 立即全部平仓信号**：任何交易所出现提现延迟，必须立刻平仓，不要等

### 可被量化的预警信号
```python
# 交易所稳定币流出预警
```

## 4. Celsius 破产 2022.06

### 事件经过
- **时间**：2022 年 6 月 12 日暂停提现 ～ 7 月 13 日申请破产
- **直接原因**：StETH 脱锚（ETH2.0 流动性危机）+ 高杠杆借贷，流动性枯竭
- **结果**：Celsius 破产，欠客户 ~$47 亿

### 量化特征
| 指标 | 数值 |
|------|------|
| Celsius 管理资产峰值 | ~$300 亿 |
| StETH/ETH 脱锚最低 | 0.936（2022.06.18） |
| BTC 跌幅（2022.06） | -37% |
| CEL 代币跌幅（2022.06） | -98% |

### 对量化策略的启示
1. **StETH 流动性风险**：Lido Staked ETH 在牛市场景下流动性充足，但熊市会出现脱锚
2. **CeFi 借贷平台 = 黑箱风险**：无法验证储备金，任何 CeFi 平台都不应存放大额资金

## 5. Wormhole 跨链黑客 2022.02

### 事件经过
- **时间**：2022 年 2 月 2 日
- **原因**：Wormhole 跨链桥漏洞，攻击者伪造了 120,000 枚 WETH 的铸币凭证
- **损失**：~$3.26 亿（当时最大 DeFi 黑客事件）

### 对量化策略的启示
1. **跨链桥风险**：任何使用跨链桥的资金都有被盗风险，套利策略需考虑桥被黑的场景
2. **跨链套利延迟风险**：跨链需要 10-60 分钟，期间市场可能剧烈波动

## 6. Ronin Bridge 黑客 2022.03

### 事件经过
- **时间**：2022 年 3 月 23 日（6 天后才发现）
- **原因**：Ronin 验证者节点被社工攻击，9 个验证者中的 5 个私钥被盗
- **损失**：173,600 ETH + 2550 万 USDC（~$6.25 亿）

### 对量化策略的启示
1. **侧链/GameFi 代币的流动性风险**：Ronin 被黑后 AXS/SLP 价格暴跌，且提现暂停数周
2. **验证者集中度风险**：任何 PoS 链如验证者集中度 > 30%，都有类似风险

## 7. ETH 合并 2022.09

### 事件经过
- **时间**：2022 年 9 月 15 日，ETH 从 PoW 切换到 PoS
- **结果**：成功合并，但 GPU 矿工抛售 ETH，短期价格下跌

### 量化特征
| 指标 | 数值 |
|------|------|
| ETH 合并前价格 | ~$1,750 |
| ETH 合并后 7 天 | ~$1,450（-17%） |
| GPU 矿工抛售量（估算） | ~$2 亿/月 |

### 对量化策略的启示
1. **重大技术升级 = 做空波动率的的机会**：合并前 IV（隐含波动率）飙升，合并后 IV 崩溃
2. **矿工抛售压力可预测**：PoW → PoS 后，矿工必须卖出 ETH 支付电费

## 8. 硅谷银行 2023.03（USDC 脱锚）

### 事件经过
- **时间**：2023 年 3 月 10 日
- **原因**：SVB 破产，Circle（USDC 发行方）有 ~$33 亿在 SVB，USDC 脱锚至 $0.87
- **结果**：USDC 恢复锚定，但 DeFi 大量清算

### 量化特征
| 指标 | 数值 |
|------|------|
| USDC 脱锚最低 | $0.87（2023.03.11） |
| ETH 跌幅（2023.03.10-11） | -9% |
| DeFi 清算量（2023.03.11） | ~$1.8 亿 |

### 对量化策略的启示
1. **稳定币储备金风险**：任何有 fractional reserve 的稳定币都有脱锚风险
2. **USDC 脱锚 = DeFi 清算机会**：脱锚时大量 DeFi 仓位被错误清算，是抄底机会
