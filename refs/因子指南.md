## 一、趋势类因子

### 1. 移动平均 MA

**公式：**
```
MA(n) = (C₁ + C₂ + ... + Cₙ) / n
```
`C` 为收盘价，`n` 为周期。

**标准参数：**
| 周期 | 用途 |
|------|------|
| MA5 | 短期快速均线 |
| MA10 | 短期 |
| MA20 | 中期，20日≈1月 |
| MA60 | 中长期，60日≈1季 |
| MA120 | 长期，半年线 |
| MA200 | 超长期，牛熊分界 |

**Python实现：**
```python
import pandas as pd

def ma(df, period):
    return df['close'].rolling(window=period).mean()

# 或用 ewm（EMA更快）
def ema(df, period):
    return df['close'].ewm(span=period, adjust=False).mean()
```

**解读规则：**
- MA多头排列（MA5>MA10>MA20>MA60）：上涨趋势，回调买入
- MA空头排列（MA5<MA10<MA20<MA60）：下跌趋势，反弹卖出
- 价格在MA20上方：偏多；在下方：偏空
- 偏离MA20超过20%：均值回归概率大

**信号逻辑：**
```
买入：MA5上穿MA20（金叉）+ 价格在MA20上方
卖出：MA5下穿MA20（死叉）
止损：跌破MA20收盘确认
```

### 2. 指数移动平均 EMA

**公式：**
```
EMA(n) = α × C + (1-α) × EMA(n-1)
α = 2 / (n + 1)
```

**标准参数：**
| 周期 | 用途 |
|------|------|
| EMA12 | MACD的快线基准 |
| EMA26 | MACD的慢线基准 |
| EMA9 | MACD的信号线 |
| EMA50 | 中期趋势 |
| EMA200 | 长期趋势 |

**Python实现：**
```python
def ema(df, period):
    return df['close'].ewm(span=period, adjust=False).mean()
```

**解读规则：**
- EMA比MA对近期价格更敏感，适合短线
- 价格在EMA200上方：长期看多
- EMA50上穿EMA200（黄金交叉）：看多信号
- EMA50下穿EMA200（死亡交叉）：看空信号

### 3. MACD

**公式：**
```
DIF = EMA12 - EMA26          # 快线
DEA = EMA(DIF, 9)            # 慢线（信号线）
MACD柱 = (DIF - DEA) × 2     # 柱状图
```

**标准参数：** (12, 26, 9)

**Python实现：**
```python
def macd(df, fast=12, slow=26, signal=9):
    ema_fast = df['close'].ewm(span=fast, adjust=False).mean()
    ema_slow = df['close'].ewm(span=slow, adjust=False).mean()
    dif = ema_fast - ema_slow
    dea = dif.ewm(span=signal, adjust=False).mean()
    macd_hist = (dif - dea) * 2
    return dif, dea, macd_hist
```

**解读规则：**
| DIF/DEA关系 | 市场状态 |
|------------|---------|
| DIF>0 且 DIF>DEA | 多头，动能增强 |
| DIF>0 且 DIF<DEA | 多头，动能减弱 |
| DIF<0 且 DIF<DEA | 空头，动能增强 |
| DIF<0 且 DIF>DEA | 空头，动能减弱 |

**信号逻辑：**
```
买入信号：
  1. DIF从负转正（零轴下方金叉）→ 初步看多
  2. DIF在零轴上方金叉（DEA）→ 强买入信号
  3. MACD柱由负转正（连续3根）→ 动能确认

卖出信号：
  1. DIF从正转负（零轴上方死叉）→ 初步看空
  2. DIF在零轴下方死叉（DEA）→ 强卖出信号
  3. MACD柱由正转负（连续3根）→ 动能确认

背离信号（最准确）：
  价格创新低，但MACD未创新低 → 底部背离，买入
  价格创新高，但MACD未创新高 → 顶部背离，卖出
```

**参数调优建议：**
- 短线（1h以下）：(8, 17, 9) 更灵敏
- 长线（日线）：(12, 26, 9) 标准
- 趋势行情：(19, 39, 9) 过滤假信号

### 4. 抛物线转向 SAR

**公式（简化）：**
```
上升趋势：SAR(n) = SAR(n-1) + AF × (EP - SAR(n-1))
下降趋势：SAR(n) = SAR(n-1) + AF × (EP - SAR(n-1))

AF = 加速因子，从0.02开始，每创新高/低加0.02，上限0.2
EP = 极值点（上升时为最高价，下降时为最低价）
```

**标准参数：** AF初始=0.02，上限=0.2

**Python实现：**
```python
def sar(high, low, af_start=0.02, af_max=0.2):
    import numpy as np
    n = len(high)
    sar = np.zeros(n)
    trend = np.zeros(n)  # 1=上升, -1=下降
    af = af_start
    ep = high[0]
    sar[0] = low[0]
    trend[0] = 1

    for i in range(1, n):
        sar[i] = sar[i-1] + af * (ep - sar[i-1])
        if trend[i-1] == 1:
            if low[i] < sar[i]:
                trend[i] = -1
                sar[i] = ep
                ep = low[i]
                af = af_start
            else:
                trend[i] = 1
                if high[i] > ep:
                    ep = high[i]
                    af = min(af + af_start, af_max)
                if low[i-1] < sar[i]:
                    sar[i] = low[i-1]
        else:
            if high[i] > sar[i]:
                trend[i] = 1
                sar[i] = ep
                ep = high[i]
                af = af_start
            else:
                trend[i] = -1
                if low[i] < ep:
                    ep = low[i]
                    af = min(af + af_start, af_max)
                if high[i-1] > sar[i]:
                    sar[i] = high[i-1]
    return sar, trend
```

**解读规则：**
- 价格在SAR上方 → 上升趋势，持有/买入
- 价格在SAR下方 → 下降趋势，卖出/做空
- SAR翻转（从上方到下方）→ 趋势反转信号

## 二、动量类因子

### 5. RSI（相对强弱指数）

**公式：**
```
RSI(n) = 100 - 100 / (1 + RS)
RS = n日内收盘涨跌幅均值 / n日内收盘跌幅均值
   = AvgGain / AvgLoss
```

**标准参数：** n=14（最常用）

**Python实现：**
```python
def rsi(df, period=14):
    delta = df['close'].diff()
    gain = delta.where(delta > 0, 0)
    loss = -delta.where(delta < 0, 0)
    avg_gain = gain.rolling(window=period).mean()
    avg_loss = loss.rolling(window=period).mean()
    rs = avg_gain / avg_loss
    return 100 - (100 / (1 + rs))
```

**解读规则（标准区间）：**
| RSI值 | 信号 | 含义 |
|-------|------|------|
| >80 | 超买 | 随时可能回调 |
| >70 | 警惕 | 进入超买区 |
| 50 | 中性 | 多空平衡 |
| <30 | 警惕 | 进入超卖区 |
| <20 | 超卖 | 随时可能反弹 |

**信号逻辑：**
```
经典用法：
  RSI<30 → 买入（超卖反弹）
  RSI>70 → 卖出（超买回调）

优化用法（结合趋势）：
  趋势向上（MA20多头）时：RSI<50 → 买入（回调低点）
  趋势向下（MA20空头）时：RSI>50 → 卖出（反弹高点）

背离（最准确）：
  价格创新低，RSI未创新低 → 底部背离 → 买入
  价格创新高，RSI未创新高 → 顶部背离 → 卖出

参数替代：
  短线：RSI(7)
  长线：RSI(21)
```

**参数对比：**
| 参数 | 适用场景 | 特点 |
|------|---------|------|
| RSI(7) | 短线 | 信号多，灵敏度更高 |
| RSI(14) | 标准 | 平衡，推荐默认 |
| RSI(21) | 长线 | 信号少，更稳定 |

### 6. KDJ（随机指标）

**公式：**
```
RSV(n) = (C - L) / (H - L) × 100
K = 2/3 × K(n-1) + 1/3 × RSV
D = 2/3 × D(n-1) + 1/3 × K
J = 3K - 2D
```
`L` = n日内最低价，`H` = n日内最高价

**标准参数：** (9, 3, 3)

**Python实现：**
```python
def kdj(high, low, close, n=9, k_mul=3, d_mul=3):
    import numpy as np
    low_n = low.rolling(window=n).min()
    high_n = high.rolling(window=n).max()
    rsv = (close - low_n) / (high_n - low_n) * 100
    k = np.zeros(len(close))
    d = np.zeros(len(close))
    j = np.zeros(len(close))
    k[0] = 50
    d[0] = 50
    for i in range(1, len(close)):
        k[i] = 2/3 * k[i-1] + 1/3 * rsv.iloc[i]
        d[i] = 2/3 * d[i-1] + 1/3 * k[i]
    j = k_mul * k - d_mul * d
    return k, d, j
```

**解读规则：**
| 区域 | 信号 |
|------|------|
| K/D/J > 80 | 超买，高位死叉看空 |
| K/D/J < 20 | 超卖，低位金叉看多 |
| J > 100 | 极度超买 |
| J < 0 | 极度超卖 |

**信号逻辑：**
```
买入：K<20 且 K从下往上穿越D（金叉）
卖出：K>80 且 K从上往下穿越D（死叉）
确认：J<0时的金叉最强；J>100时的死叉最强
```

### 7. CCI（顺势指标）

**公式：**
```
TP = (H + L + C) / 3              # 典型价格
SMA = MA(TP, n)                   # 典型价格的n日均线
CCI(n) = (TP - SMA) / (0.015 × MAD)
MAD = TP与SMA的绝对偏差均值
```

**标准参数：** n=20

**Python实现：**
```python
def cci(high, low, close, period=20):
    tp = (high + low + close) / 3
    sma = tp.rolling(window=period).mean()
    mad = (tp - sma).abs().rolling(window=period).mean()
    return (tp - sma) / (0.015 * mad)
```

**解读规则：**
| CCI值 | 信号 |
|-------|------|
| >+100 | 超买，上涨动能强 |
| <-100 | 超卖，下跌动能强 |
| 0附近 | 无趋势 |

### 8. 动量指标 MOM

**公式：**
```
MOM(n) = C - C₋ₙ
MOM_ROC(n) = (C - C₋ₙ) / C₋ₙ × 100
```

**标准参数：** n=10 或 n=20

**Python实现：**
```python
def momentum(close, period=10):
    return close.diff(period)

def roc(close, period=10):
    return close.pct_change(period) * 100
```

**解读规则：**
- MOM>0：上涨动量，价格有上升惯性
- MOM<0：下跌动量，价格有下降惯性
- MOM背离：与价格走势背离时反转信号

## 三、波动类因子

### 9. 布林带 BOLL

**公式：**
```
中轨 = MA(close, n)
上轨 = 中轨 + 2 × STD(close, n)
下轨 = 中轨 - 2 × STD(close, n)
带宽 = (上轨 - 下轨) / 中轨 × 100
```

**标准参数：** n=20，标准差=2

**Python实现：**
```python
def bollinger(df, period=20, std_dev=2):
    ma = df['close'].rolling(window=period).mean()
    std = df['close'].rolling(window=period).std()
    upper = ma + std_dev * std
    lower = ma - std_dev * std
    bandwidth = (upper - lower) / ma * 100
    return upper, ma, lower, bandwidth
```

**解读规则：**
| 情况 | 信号 |
|------|------|
| 价格触及下轨 | 超卖，可能反弹 |
| 价格触及上轨 | 超买，可能回落 |
| 布林带收窄（带宽<5%） | 突破在即 |
| 布林带开口放大 | 趋势确认 |
| 价格穿越中轨 | 多空转换 |

**带宽公式（判断震荡 vs 趋势）：**
```
带宽 < 5%：极度震荡，突破在即 → 布林套利
带宽 > 10%：趋势明确 → 趋势策略
带宽逐渐扩大 → 趋势延续
```

### 10. ATR（平均真实波幅）

**公式：**
```
TR = max(H-L, |H-C_prev|, |L-C_prev|)   # 真实波幅
ATR(n) = MA(TR, n)
```

**标准参数：** n=14

**Python实现：**
```python
def atr(high, low, close, period=14):
    tr1 = high - low
    tr2 = (high - close.shift()).abs()
    tr3 = (low - close.shift()).abs()
    tr = pd.concat([tr1, tr2, tr3], axis=1).max(axis=1)
    return tr.rolling(window=period).mean()
```

**解读规则：**
- ATR越大：市场波动越剧烈
- ATR越小：市场越平静（震荡或蓄势）
- ATR突然放大：趋势启动或反转信号

**实战应用（仓位管理）：**
```
止损距离 = 2 × ATR(14)
建议仓位 = 账户 × 1% / 止损距离
例如：账户10万，ATR=500，止损距离=1000点
     仓位 = 100000 × 1% / 1000 = 1手
```

## 四、成交量类因子

### 11. OBV（能量潮）

**公式：**
```
如果 C > C_prev：OBV = OBV_prev + V
如果 C < C_prev：OBV = OBV_prev - V
如果 C = C_prev：OBV = OBV_prev
```

**Python实现：**
```python
def obv(df):
    obv = (np.sign(df['close'].diff()) * df['volume']).fillna(0).cumsum()
    return obv
```

**解读规则：**
- OBV创新高 + 价格创新高 → 上涨趋势健康
- OBV创新低 + 价格创新低 → 下跌趋势持续
- OBV背离价格 → 趋势反转信号
- OBV横盘 + 价格大涨 → 主力未参与，警惕

---

### 12. VWAP（成交量加权平均价）

**公式：**
```
VWAP = Σ(P×V) / ΣV
```

**Python实现：**
```python
def vwap(df):
    typical_price = (df['high'] + df['low'] + df['close']) / 3
    return (typical_price * df['volume']).cumsum() / df['volume'].cumsum()
```

**解读规则：**
- 价格在VWAP上方 → 偏多
- 价格在VWAP下方 → 偏空
- 日内交易关键：开盘价 vs VWAP

## 五、链上因子

### 13. MVRV（市场价值与已实现价值比）

**公式：**
```
MVRV = 市值 / 已实现市值
```

**解读规则（Glassnode数据）：**

|---------|---------|
| <1.0 | 严重低估，历史大底 |
| 1.0~2.0 | 低估 |
| 2.0~3.5 | 正常 |
| 3.5~5.0 | 高估，注意风险 |

```
MVRV > 3.5 → 减仓信号
MVRV < 1.5 → 买入信号
```

## 六、因子组合与冲突处理

### 常用组合方案

| 行情 | 推荐组合 | 逻辑 |
|------|---------|------|
| 趋势确认 | MA(20,60) + MACD(12,26,9) | 双趋势过滤 |
| 超买超卖 | RSI(14) + BOLL(20,2) | 双重确认 |
| 动量共振 | RSI + KDJ + CCI | 三指标共振 |
| 突破系统 | BOLL收窄 + ATR放大 | 突破信号 |
| 完整系统 | RSI + MACD + BOLL + ATR + VOL | 5指标共振 |

### 因子冲突处理原则

1. **趋势优先**：先判断趋势方向（MA/MACD），再决定用哪个RSI区间
2. **共振加分**：2个以上因子同向 → 信号加强
3. **时间过滤**：指标信号 + 等待1-2根K线确认再入场
4. **量能确认**：任何信号必须放量确认

### 因子相关性（避免冗余）

| 因子组合 | 相关性 | 建议 |
|---------|--------|------|
| RSI + KDJ | 高(0.8+) | 二选一 |
| MA + EMA | 高(0.95+) | 二选一 |
| MACD + RSI | 中(0.6~0.8) | 可组合 |
| BOLL + ATR | 中(0.5~0.7) | 可组合 |
| RSI + OBV | 低(0.3~0.5) | 推荐组合 |
| MACD + BOLL | 低(0.3~0.6) | 推荐组合 |
| ATR + BOLL带宽 | 高(0.7+) | 二选一 |

### VIF检验标准

```
VIF < 5：因子独立，使用无问题
VIF 5~10：因子有共线性，考虑精简
VIF > 10：严重共线性，必须移除
```

## 十四、资金费率因子（Funding Rate）v3.2 NEW

> Web3 独有因子，传统量化没有对应物

### 公式
```
Funding Rate = 每8小时结算一次的永续合约资金费率
正费率 → 多头付费给空头（多头拥挤）
负费率 → 空头付费给多头（空头拥挤）
```

### 信号逻辑
| 条件 | 信号 | 含义 |
|------|------|------|
| 连续3次 > 0.03% | 做空 | 多头过度拥挤，回调概率大 |
| 连续3次 < -0.03% | 做多 | 空头过度拥挤，反弹概率大 |
| 费率从极端回归0 | 平仓 | 拥挤缓解，套利窗口关闭 |

### Python 实现
```python
from indicators import calc_funding_signal

# funding_rates: [{'rate': 0.0003, 'time': '2024-01-01'}, ...]
signals = calc_funding_signal(funding_rates,
    threshold_high=0.0003,   # 0.03%
    threshold_low=-0.0003,   # -0.03%
    lookback=3)              # 连续3次
```

### Binance API 获取资金费率
```python
import urllib.request, json

```

### 搭配建议
- Funding + OI → 拥挤度判断（同向=真拥挤，反向=假信号）
- Funding + MACD → 趋势+拥挤双重确认

## 十五、持仓量因子（Open Interest）v3.2 NEW

> OI 变化反映资金流入流出，是趋势确认的关键

### 公式
```
OI百分位 = 当前OI在过去30日OI中的排名 / 30 × 100
高百分位(>80) + 价格上涨 + 高Funding → 多头拥挤顶部信号
低百分位(<20) + 价格下跌 → 空头出清，底部信号
```

### 信号逻辑
| OI百分位 | 价格方向 | 信号 |
|---------|---------|------|
| >80% | 上涨 | ⚠️ 多头拥挤，警惕回调 |
| >80% | 下跌 | 🔴 多头爆仓中，不要接飞刀 |
| <20% | 下跌 | 🟢 空头出清，关注反转 |
| <20% | 上涨 | ✅ 资金重新进场，趋势健康 |

### Python 实现
```python
from indicators import calc_oi_percentile

# oi_series: [125000.5, 126000.3, ...]
oi_pct = calc_oi_percentile(oi_series, lookback=30)
# 返回 0-100 的百分位序列
```

### Binance API 获取 OI

## 十六、CVD 累计成交量差（Cumulative Volume Delta）v3.2 NEW

> CVD 衡量主动买卖力量，与价格背离是早期反转信号

### 公式
```
CVD = 累计(成交量 × 方向系数)
方向系数 = (Close - Open) / (High - Low)  # K线级近似
CVD上升 → 主动买方更强
CVD下降 → 主动卖方更强
```

### 信号逻辑
| CVD与价格 | 信号 |
|----------|------|
| 价格创新高 + CVD未创新高 | 🔴 顶背离，卖出信号 |
| 价格创新低 + CVD未创新低 | 🟢 底背离，买入信号 |
| CVD与价格同向 | ✅ 趋势确认 |

### Python 实现
```python
from indicators import calc_cvd

cvd = calc_cvd(candles)
# 返回 CVD 序列
```

### 注意
- 精确 CVD 需要逐笔 tick 数据，K线级 CVD 是近似
- CVD 背离信号应配合 RSI/MACD 确认，不单独使用
