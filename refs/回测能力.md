## 一、回测标准10步流程

```
Step 1: 定义问题        → 明确策略逻辑和假设
Step 2: 数据准备        → 获取干净的历史K线
Step 3: 策略实现         → 写代码生成买卖信号
Step 4: 模拟交易         → 按信号模拟下单
Step 5: 绩效计算         → 收益率、夏普、最大回撤
Step 6: 参数敏感性分析   → 避免过度拟合
Step 7: 样本外测试       → 验证策略普适性
Step 8: 压力测试         → 极端行情下表现
Step 9: 实盘验证         → 模拟盘 → 小资金实盘
Step 10: 持续监控        → 实盘记录与回测对比
```

### 策略1: 均线交叉

```python
def ma_crossover_strategy(df, params):
    df = df.copy()
    df['MA5'] = df['close'].rolling(5).mean()
    df['MA20'] = df['close'].rolling(20).mean()
    
    # 仓位状态
    position = 0
    entries = []
    
    for i in range(20, len(df)):
        row = df.iloc[i]
        prev = df.iloc[i-1]
        
        # 买入信号：MA5上穿MA20
        if prev['MA5'] <= prev['MA20'] and row['MA5'] > row['MA20'] and position == 0:
            position = params['position_size']
            entries.append({
                'type': 'BUY',
                'price': row['close'] * (1 + params['slippage']),
                'date': row['timestamp']
            })
        
        # 卖出信号：MA5下穿MA20
        elif prev['MA5'] >= prev['MA20'] and row['MA5'] < row['MA20'] and position > 0:
            position = 0
            entries.append({
                'type': 'SELL',
                'price': row['close'] * (1 - params['slippage']),
                'date': row['timestamp']
            })
    
    return entries
```

### 策略2: 布林带均值回归

```python
def bollinger_reversion(df, params):
    df = df.copy()
    df['MA20'] = df['close'].rolling(20).mean()
    df['STD'] = df['close'].rolling(20).std()
    df['UPPER'] = df['MA20'] + 2 * df['STD']
    df['LOWER'] = df['MA20'] - 2 * df['STD']
    
    position = 0
    entries = []
    
    for i in range(20, len(df)):
        row = df.iloc[i]
        
        # 买入：触及下轨
        if row['close'] <= row['LOWER'] and position == 0:
            position = params['position_size']
            entries.append({
                'type': 'BUY',
                'price': row['close'] * (1 + params['slippage']),
                'date': row['timestamp']
            })
        
        # 卖出：触及上轨
        elif row['close'] >= row['UPPER'] and position > 0:
            position = 0
            entries.append({
                'type': 'SELL',
                'price': row['close'] * (1 - params['slippage']),
                'date': row['timestamp']
            })
    
    return entries
```

### 策略3: MACD 金叉死叉

```python
def macd_strategy(df, params):
    df = df.copy()
    df['EMA12'] = df['close'].ewm(span=12, adjust=False).mean()
    df['EMA26'] = df['close'].ewm(span=26, adjust=False).mean()
    df['DIF'] = df['EMA12'] - df['EMA26']
    df['DEA'] = df['DIF'].ewm(span=9, adjust=False).mean()
    
    position = 0
    entries = []
    
    for i in range(26, len(df)):
        row = df.iloc[i]
        prev = df.iloc[i-1]
        
        # 买入：DIF在零轴上方金叉
        if prev['DIF'] <= prev['DEA'] and row['DIF'] > row['DEA'] and position == 0:
            position = params['position_size']
            entries.append({'type': 'BUY', 'price': row['close'], 'date': row['timestamp']})
        
        # 卖出：DIF在零轴下方死叉
        elif prev['DIF'] >= prev['DEA'] and row['DIF'] < row['DEA'] and position > 0:
            position = 0
            entries.append({'type': 'SELL', 'price': row['close'], 'date': row['timestamp']})
    
    return entries
```

## 四、绩效计算

### 完整绩效指标

```python
import numpy as np

def calculate_performance(df, entries, params):
    """计算完整绩效指标"""
    
    # 初始资金
    balance = params['initial_balance']
    balance_history = [balance]
    
    trades = []
    wins, losses = [], []
    peak = balance
    
    i = 0  # data index pointer
    position = 0
    entry_price = 0
    
    for entry in entries:
        if entry['type'] == 'BUY':
            position = balance * params['position_size'] / entry['price']
            entry_price = entry['price']
            balance *= (1 - params['fee'])
        
        elif entry['type'] == 'SELL' and position > 0:
            # 持仓期间按收盘价计算
            balance = position * entry['price']
            balance *= (1 - params['fee'])
            pnl = (entry['price'] - entry_price) / entry_price * 100
            trades.append({'pnl': pnl, 'date': entry['date']})
            if pnl > 0:
                wins.append(pnl)
            else:
                losses.append(pnl)
            position = 0
            balance_history.append(balance)
            peak = max(peak, balance)
    
    # 如果还有持仓，按最后收盘价结算
    if position > 0:
        balance = position * df['close'].iloc[-1]
    
    # === 核心指标 ===
    total_return = (balance - params['initial_balance']) / params['initial_balance'] * 100
    
    # 年化收益率
    days = (df['timestamp'].iloc[-1] - df['timestamp'].iloc[0]).days
    years = max(days / 365, 0.01)
    annualized_return = ((balance / params['initial_balance']) ** (1 / years) - 1) * 100
    
    # 最大回撤
    peak = params['initial_balance']
    max_drawdown = 0
    for b in balance_history:
        peak = max(peak, b)
        dd = (peak - b) / peak * 100
        max_drawdown = max(max_drawdown, dd)
    
    # 夏普比率
    returns = np.diff(balance_history) / balance_history[:-1]
    if len(returns) > 1 and np.std(returns) > 0:
        sharpe = (np.mean(returns) * 252 - 0.02) / (np.std(returns) * np.sqrt(252))
    else:
        sharpe = 0
    
    # 胜率 & 盈亏比
    win_rate = len(wins) / len(trades) * 100 if trades else 0
    avg_win = np.mean(wins) if wins else 0
    avg_loss = abs(np.mean(losses)) if losses else 0
    profit_factor = avg_win / avg_loss if avg_loss > 0 else 0
    
    return {
        'initial_balance': params['initial_balance'],
        'final_balance': balance,
        'total_return': f'{total_return:.2f}%',
        'annualized_return': f'{annualized_return:.2f}%',
        'max_drawdown': f'{max_drawdown:.2f}%',
        'sharpe_ratio': f'{sharpe:.2f}',
        'total_trades': len(trades),
        'win_rate': f'{win_rate:.1f}%',
        'avg_win': f'{avg_win:.2f}%',
        'avg_loss': f'{avg_loss:.2f}%',
        'profit_factor': f'{profit_factor:.2f}'
    }
```

### 绩效解读标准

| 指标 | 优秀 | 合格 | 可疑 |
|------|------|------|------|
| 年化收益 | >50% | >20% | >100% |
| 夏普比率 | >1.5 | >1.0 | <0.5 |
| 最大回撤 | <10% | <20% | <5% |
| 胜率 | 50~60% | >40% | >70% |
| 盈亏比 | >2.0 | >1.5 | >3.0 |
| 年交易次数 | 20~200 | 10~500 | <10 或 >1000 |

## 五、回测陷阱与防范

### 五大陷阱

| 陷阱 | 原因 | 防范方法 |
|------|------|---------|
| **过度拟合** | 参数调到完美 | 参数越少越好；参数变化时绩效应稳定 |
| **未来函数** | 使用了未来数据 | 严格用前N根K线计算指标 |
| **幸存者偏差** | 只回测活下来的币 | 包含已归零币种 |
| **流动性偏差** | 小市值币无滑点 | 按真实可成交深度模拟 |
| **手续费忽视** | 低估交易成本 | Binance 0.1%现货，0.04%/0.06%合约 |

### 参数敏感性测试

```python
def parameter_sanity_check(df, param_name, param_values, base_params):
    """
    测试参数在合理范围内是否稳定
    如果某个值特别突出，说明策略对该参数过于敏感
    """
    results = []
    for val in param_values:
        params = base_params.copy()
        params[param_name] = val
        entries = ma_crossover_strategy(df, params)
        perf = calculate_performance(df, entries, params)
        results.append({'param': val, 'return': perf['total_return']})
    
    # 计算参数变化时的收益标准差
    # 标准差越小 = 策略越稳定
    returns = [r['return'] for r in results]
    std = np.std([float(r.rstrip('%')) for r in returns])
    return std
```

```

  └── 持续3个月达标 → 放大到50%
  └── 持续6个月达标 → 全量运行
```

## 十、Walk-Forward 滚动回测（v3.4 新增）

### 10.1 为什么需要 Walk-Forward？

**传统回测的问题**：
- 使用全部历史数据优化参数 → 过拟合风险极高
- 无法验证策略在"未知数据"上的表现
- 参数在样本内完美，样本外失效

**Walk-Forward 解决方案**：
- 将历史数据分为多个滚动窗口
- 每个窗口内：前段训练优化 → 后段样本外测试
- 模拟"边交易边优化"的真实场景

---

### 10.2 核心概念

| 术语 | 含义 |
|------|------|
| IS（In-Sample） | 训练窗口，用于参数优化 |
| OOS（Out-Of-Sample） | 测试窗口，验证优化后的参数 |
| 滚动步长 | 每次向前滚动的K线数量 |
| 稳定性 | OOS收益与IS收益的比值（>0.6 为稳定） |

**标准窗口设置**：
```
总数据：3年（1095天）
IS窗口：1年（252天）← 训练
OOS窗口：3个月（63天）← 测试
滚动步长：3个月（63天）
→ 共 9 次滚动验证
```

### 10.4 稳定性判断标准

| 稳定性得分 | 含义 | 建议 |
|-----------|------|------|
| > 0.8 | 高度稳健 | 可实盘 |
| 0.6 - 0.8 | 稳健 | 小资金试错 |
| 0.4 - 0.6 | 不稳定 | 增加过滤条件 |
| < 0.4 | 严重过拟合 | 放弃策略 |

**过拟合检测**：
- OOS 收益 < IS 收益 × 0.5 → 过拟合
- OOS 最大回撤 > IS 最大回撤 × 1.5 → 过拟合
- OOS 夏普 < IS 夏普 × 0.5 → 过拟合

---

### 10.5 Walk-Forward vs 传统回测

| 维度 | 传统回测 | Walk-Forward |
|------|---------|--------------|
| 数据利用 | 一次性 | 滚动多次 |
| 过拟合检测 | 难 | 内置 |
| 样本外验证 | 单次 | 多次 |
| 稳定性评估 | 无 | 有（稳定性得分） |
| 实盘贴合度 | 低 | 高 |

### 10.7 实战建议

1. **最少 3 年数据**：Walk-Forward 需要足够多的滚动窗口（至少 6 次）
2. **OOS 窗口 ≥ IS 窗口的 25%**：太短的 OOS 无法验证
3. **稳定性 > 0.6 才考虑实盘**：低于此值说明策略对参数敏感
4. **结合参数敏感性分析**：即使稳定性高，也要检查参数是否敏感
5. **多品种验证**：在 BTC/ETH/SOL 上分别跑 Walk-Forward，都稳定才实盘
