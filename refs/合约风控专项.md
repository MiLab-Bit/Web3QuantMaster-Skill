## 1. 强平价计算

### 永续合约（USDT-Margined）

**维持保证金率（MM Rate）**：Binance USDT永续 = 0.5%

```
强平价（做多）= 入场价 × (1 - 1/杠杆倍数 - MM率)
强平价（做空）= 入场价 × (1 + 1/杠杆倍数 + MM率)
```

| 杠杆 | 做多强平价（入场价=10000） | 做空强平价 |
|------|--------------------------|-----------|
| 3x | 10000 × (1 - 0.333 - 0.005) = **$9,620** | **$10,380** |
| 5x | 10000 × (1 - 0.20 - 0.005) = **$9,750** | **$10,250** |
| 10x | 10000 × (1 - 0.10 - 0.005) = **$8,950** | **$11,050** |
| 20x | 10000 × (1 - 0.05 - 0.005) = **$9,450** | **$10,550** |

**Python 计算：**
```python
def calc_liquidation_price(entry_price, leverage, direction='long', mm_rate=0.005):
    if direction == 'long':
        return entry_price * (1 - 1/leverage - mm_rate)
    else:
        return entry_price * (1 + 1/leverage + mm_rate)

# 示例
entry = 67000
for lev in [3, 5, 10, 20]:
    liq_long = calc_liquidation_price(entry, lev, 'long')
    liq_short = calc_liquidation_price(entry, lev, 'short')
    print(f'{lev}x: Long强平=${liq_long:,.0f} | Short强平=${liq_short:,.0f}')
```

### 币本位合约（Coin-Margined）

强平价 = (调整系数 - 合约乘数 × 方向系数 × 维持担保率) / (入场价 × 方向系数 × 合约乘数 - 未实现盈亏)
（更复杂，建议直接使用交易所 API 获取）

## 2. 资金费率套利计算

### 什么是资金费率（Funding Rate）

永续合约每8小时结算一次，资金费率由多空双方交换：
- 资金费率 > 0：多头付钱给空头（空头获利）
- 资金费率 < 0：空头付钱给多头（多头获利）

**实际收益 = 资金费率收益 - 手续费损耗**

```python
def calc_funding_arbitrage(funding_rate, maker_fee=0.0002, days=30):
    """
    资金费率套利年化收益计算
    funding_rate: 单次结算费率（如 0.0001 = 0.01%）
    maker_fee: 交易所Maker手续费率
    """
    daily_settlements = 3  # 每天3次结算
    daily_net = funding_rate - maker_fee  # 每次净收益（扣除手续费）

    # 年化（简化）
    annual_return = daily_net * daily_settlements * 365

    # 30天累计
    monthly_return = daily_net * daily_settlements * days

    return {
        'annual_return_pct': annual_return * 100,
        'monthly_return_pct': monthly_return * 100,
        'daily_net_pct': daily_net * 100,
        'compounding_effect': (1 + daily_net) ** (daily_settlements * 365) - 1,
    }

# 示例：资金费率 0.01%（每小时结算前）
result = calc_funding_arbitrage(0.0001)
print(f"年化: {result['annual_return_pct']:.1f}%")  # ≈ 10.95%
print(f"月化: {result['monthly_return_pct']:.2f}%")  # ≈ 0.91%
```

**判断标准：**
- 年化 > 10%：高费率环境，适合做空方套利
- 年化 3-10%：中等，可作为增强收益手段
- 年化 < 3%：费率收益有限，不值得专门操作

## 3. 合约滑点实测方法

合约滑点（Slippage）在流动性低或大单时尤为明显。

**通过订单簿深度估算滑点：**

```python
def estimate_slippage(orderbook, side='buy', amount_pct=0.01):
    """
    通过订单簿深度估算滑点
    side: 'buy'（做多）或 'sell'（做空）
    amount_pct: 占资金的比例（0.01 = 1%）
    """
    if side == 'buy':
        levels = orderbook['asks']  # 卖单（做多要买）
    else:
        levels = orderbook['bids']  # 买单（做空要买）

    total_cost = 0.0
    total_qty = 0.0
    base_price = levels[0][0] if levels else 0

    for price, qty in levels:
        cost = price * qty
        total_cost += cost
        total_qty += qty
        if total_cost >= amount_pct * base_price * 100:  # 假设账户规模
            break

    avg_price = total_cost / total_qty if total_qty > 0 else base_price
    slippage = (avg_price - base_price) / base_price * 100

    return {
        'base_price': base_price,
        'avg_fill_price': avg_price,
        'slippage_pct': slippage,
        'assessment': 'LOW' if slippage < 0.1 else 'MEDIUM' if slippage < 0.5 else 'HIGH'
    }
```

**滑点容忍阈值建议：**
| 交易风格 | 最大可接受滑点 |
|---------|-------------|
| 短线（< 1h）| 0.1% |
| 波段（1-7天）| 0.3% |
| 长线（> 7天）| 0.5% |
| 超过阈值 | 建议分批建仓 |

## 4. 合约 vs 现货对冲操作

### 用途
持有现货害怕下跌，用合约做空对冲（等效于"买保险"）

### 计算对冲比例

```python
def calc_hedge_ratio(position_value, futures_price, leverage=1):
    """
    计算对冲所需合约数量
    position_value: 现货持仓市值（USD）
    futures_price: 合约当前价格
    leverage: 合约杠杆倍数
    """
    # 合约面值：通常为 USDT（如 Binance 永续 1张 = $100）
    CONTRACT_SIZE = 100

    # 所需合约数量（面值方式）
    futures_qty = position_value / futures_price / leverage

    # 换算为合约张数
    contracts = futures_qty * leverage  # 注意：这里简化了

    # 对冲比例（对冲市值 / 现货市值）
    hedge_ratio = (futures_price * futures_qty) / position_value

    return {
        'futures_qty': futures_qty,
        'contracts': contracts,
        'hedge_ratio': hedge_ratio,  # 1.0 = 完全对冲
        'note': 'hedge_ratio=1.0 完全对冲, <1.0 部分对冲'
    }

# 示例：持有 1 BTC 现货（现价 67000，总值 $67,000）
# 用10x合约做空对冲
result = calc_hedge_ratio(67000, 67000, leverage=10)
print(f"对冲比例: {result['hedge_ratio']:.2f}")  # 1.0 = 完全对冲
print(f"所需合约数量: {result['futures_qty']:.4f}")
```

### 对冲成本分析

| 对冲方式 | 成本 | 收益 |
|---------|------|------|
| 完全对冲（1:1）| 手续费 + 资金费率 | 消除下行风险 |
| 部分对冲（50%）| 手续费 + 资金费率 | 保留50%上行空间 |
| 零成本领口 | 买看空期权 + 卖看涨期权 | 有限成本/收益 |

## 5. 多合约仓位汇总

当同时持有多个合约仓位时，需要汇总所有合约的强平风险。

```python
def portfolio_liquidation_analysis(positions):
    """
    positions: [
        {'symbol': 'BTCUSDT', 'side': 'long', 'entry': 67000, 'qty': 0.5, 'leverage': 5},
        {'symbol': 'ETHUSDT', 'side': 'short', 'entry': 3500, 'qty': 2, 'leverage': 3},
    ]
    返回：各仓位强平价 + 最危险仓位排名
    """
    results = []
    for pos in positions:
        liq_price = calc_liquidation_price(
            pos['entry'], pos['leverage'], pos['side']
        )
        pos_value = pos['entry'] * pos['qty']

        # 计算距离现价的百分比（需要实时价格，这里用 entry 估算）
        dist_to_liq = abs(pos['entry'] - liq_price) / pos['entry'] * 100

        results.append({
            **pos,
            'liq_price': liq_price,
            'pos_value_usd': pos_value,
            'distance_to_liq_pct': dist_to_liq,
            'risk_level': 'SAFE' if dist_to_liq > 20 else 'MEDIUM' if dist_to_liq > 10 else 'DANGER'
        })

    # 按危险程度排序
    results.sort(key=lambda x: x['distance_to_liq_pct'])
    return results

# 示例
positions = [
    {'symbol': 'BTCUSDT', 'side': 'long', 'entry': 67000, 'qty': 0.5, 'leverage': 10},
    {'symbol': 'SOLUSDT', 'side': 'long', 'entry': 180, 'qty': 50, 'leverage': 5},
]
for r in portfolio_liquidation_analysis(positions):
    print(f"{r['symbol']} {r['side']} {r['leverage']}x: "
          f"强平价=${r['liq_price']:,.2f}, "
          f"距离={r['distance_to_liq_pct']:.1f}%, "
          f"风险={r['risk_level']}")
```

## 6. 极端行情风控清单

| 场景 | 触发条件 | 操作 |
|------|---------|------|
| 插针预警 | 1h内波动 > 15% | 立即检查强平线，空仓者观望 |
| 资金费率飙升 | 3x合约费率 > 0.1%/8h | 检查套利机会，考虑反向 |
| 流动性枯竭 | 订单簿深度 < 平均30% | 减小仓位，避开大单 |
| 交易所宕机 | API 返回异常 | 暂停所有操作，等恢复 |
| 链上拥堵 | GAS费 > 500 gwei | 延迟非必要操作 |

## 7. 衍生品拥挤度风控规则 v3.2 NEW

> 资金费率 + OI 是 Web3 独有的风控信号，传统量化没有对应物

### 拥挤度判断矩阵

| 资金费率 | OI 百分位 | 含义 | 操作 |
|---------|----------|------|------|
| > 0.03% 连续3次 | > 80% | 🔴 多头极度拥挤 | 禁止新开多，考虑开空对冲 |
| > 0.03% 连续3次 | < 50% | 🟡 多头拥挤但OI未跟上 | 轻仓试空，止损严格 |
| < -0.03% 连续3次 | > 80% | 🔴 空头极度拥挤 | 禁止新开空，考虑开多对冲 |
| < -0.03% 连续3次 | < 50% | 🟡 空头拥挤但OI未跟上 | 轻仓试多，止损严格 |
| 正常(±0.01%) | 任意 | 🟢 无拥挤信号 | 正常交易 |

### 清算簇风控

当大量杠杆仓位接近强平价时，价格触及密集强平区会引发连锁清算（瀑布效应）：

```python
def check_liquidation_cluster(oi, avg_leverage, price, exchange='binance'):
    """
    估算清算簇距离
    oi: 当前持仓量
    avg_leverage: 平均杠杆倍数
    price: 当前价格
    """
    # 假设均匀分布，估算大多数仓位的价格区间
    est_range = price / avg_leverage  # 大约在这个范围内集中了大量仓位
    
    # 如果价格距强平区 < 5%，发出预警
    distance_pct = est_range / price * 100
    if distance_pct < 5:
        return 'DANGER', f'清算簇距离仅 {distance_pct:.1f}%，警惕瀑布'
    elif distance_pct < 10:
        return 'WARNING', f'清算簇距离 {distance_pct:.1f}%，关注'
    else:
        return 'SAFE', '清算簇距离安全'
```

### 资金费率 Regime 风控

| Funding Regime | 条件 | 操作规则 |
|---------------|------|----------|
| 极端正 | 单次 > 0.1% | 禁止开多，只允许平多或开空 |
| 高正 | 连续3次 > 0.03% | 减多仓至 50%，可开空对冲 |
| 正常 | ±0.03% 以内 | 正常交易 |
| 高负 | 连续3次 < -0.03% | 减空仓至 50%，可开多对冲 |
| 极端负 | 单次 < -0.1% | 禁止开空，只允许平空或开多 |

### DEX vs CEX 风险对比

| 维度 | CEX（Binance/OKX） | DEX（dYdX/GMX） |
|------|-------------------|-----------------|
| 资金安全 | 交易所托管风险 | 合约托管，无跑路风险 |
| 清算机制 | 预言机+保险基金 | 预言机+流动性池 |
| 滑点 | 小（深度好） | 大（AMM机制） |
| 资金费率 | 8h结算，相对稳定 | 1h结算，波动大 |
| 极端行情 | 可能拔网线 | 链上不可阻挡，但可能预言机延迟 |
| 风控建议 | 关注交易所公告 | 关注预言机延迟和Gas费 |
