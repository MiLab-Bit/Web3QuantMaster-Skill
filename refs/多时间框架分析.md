## 1. 为什么要做多时间框架分析？

### 单一时间框架的问题
```
只看 1h 图：
  → 被短期波动干扰，看不清主趋势
  → 容易追涨杀跌

只看日线：
  → 入场太晚，止损太大
  → 资金利用率低
```

### 多时间框架的优势
```
日线：判断主趋势（做多还是做空）
4h：判断中期方向（确认日线趋势）
1h：寻找入场点（精确入场）
15m：微调入场（优化止损）
```

### 案例：BTC 2024 年 3 月
```
日线：上涨趋势（EMA50 > EMA200）→ 只做多
4h：回调到 EMA50 → 准备买入
1h：RSI 超卖 + 价格触及布林带下轨 → 买入信号
15m：确认反转（突破下降趋势线）→ 精确入场
```

## 2. 多时间框架分析框架

### 三重过滤系统（Triple Screen System）
```
第 1 屏（周线/日线）：趋势判断
  → 用趋势指标（EMA/MA/MACD）
  → 决定做多还是做空

第 2 屏（4h/1h）：入场时机
  → 用震荡指标（RSI/KDJ/布林带）
  → 寻找逆势入场点

第 3 屏（15m/5m）：精确入场
  → 用价格行为（K 线形态/突破）
  → 确认入场，设置止损
```

### 时间框架比例
```
经验法则：相邻时间框架比例 ≈ 4:1 到 6:1

示例：
  日线 → 4h（比例 6:1）→ 1h（比例 4:1）
  4h → 1h（比例 4:1）→ 15m（比例 4:1）
```

## 3. 时间框架选择指南

### 根据持仓时间选择
| 持仓时间 | 趋势框架 | 入场框架 | 精确入场 |
|---------|---------|---------|-----------|
| **日内（<1d）** | 4h | 1h | 15m |
| **短线（1-7d）** | 日线 | 4h | 1h |
| **中线（7d-1M）** | 周线 | 日线 | 4h |
| **长线（>1M）** | 月线 | 周线 | 日线 |

### Web3 独有：7x24 市场的时间框架调整
```
传统金融：
  日线 = 24 小时（交易时间 6.5h）
  → 一天只有 6.5h 数据

Web3（7x24）：
  日线 = 24 小时（连续交易）
  → 一天有 24h 数据
  
调整：
  用 3 日线（3D）代替周线
  用 12h 代替日线
```

## 4. 趋势判断：自上而下

### 步骤 1：最高时间框架（周线/3D）
```
判断主趋势：
  EMA20 > EMA50 > EMA100 → 强上涨趋势
  EMA20 < EMA50 < EMA100 → 强下跌趋势
  横盘 → 不交易或降低仓位
```

### 步骤 2：中间时间框架（日线/12h）
```
确认趋势：
  与最高框架同向 → 趋势确认
  与最高框架反向 → 可能是回调，等待
```

### 步骤 3：入场时间框架（4h/1h）
```
寻找入场点：
  主趋势向上 → 等待回调到支撑位
  主趋势向下 → 等待反弹到阻力位
```

### Python 实现：趋势判断
```python
# multi_tf_trend.py
import numpy as np

def detect_trend(candles_tf1, candles_tf2, candles_tf3):
    """
    三重时间框架趋势判断
    
    参数：
      candles_tf1: 最高时间框架（如周线）
      candles_tf2: 中间时间框架（如日线）
      candles_tf3: 入场时间框架（如 4h）
    
    返回：
      trend: 'UP' / 'DOWN' / 'SIDEWAYS'
      confidence: 0.0-1.0
    """
    from indicators import calc_ema
    
    # 最高框架趋势
    closes1 = [c['close'] for c in candles_tf1]
    ema20_1 = calc_ema(closes1, 20)
    ema50_1 = calc_ema(closes1, 50)
    ema100_1 = calc_ema(closes1, 100)
    
    if ema20_1[-1] and ema50_1[-1] and ema100_1[-1]:
        if ema20_1[-1] > ema50_1[-1] > ema100_1[-1]:
            trend1 = 'UP'
        elif ema20_1[-1] < ema50_1[-1] < ema100_1[-1]:
            trend1 = 'DOWN'
        else:
            trend1 = 'SIDEWAYS'
    else:
        trend1 = 'UNKNOWN'
    
    
    # 中间框架趋势
    closes2 = [c['close'] for c in candles_tf2]
    ema20_2 = calc_ema(closes2, 20)
    ema50_2 = calc_ema(closes2, 50)
    
    if ema20_2[-1] and ema50_2[-1]:
        if ema20_2[-1] > ema50_2[-1]:
            trend2 = 'UP'
        elif ema20_2[-1] < ema50_2[-1]:
            trend2 = 'DOWN'
        else:
            trend2 = 'SIDEWAYS'
    else:
        trend2 = 'UNKNOWN'
    
    
    # 综合判断
    if trend1 == trend2 and trend1 != 'SIDEWAYS':
        confidence = 0.9
        trend = trend1
    elif trend1 == trend2:
        confidence = 0.5
        trend = trend1
    else:
        confidence = 0.3
        trend = trend2  # 以中间框架为准
    
    return {
        'trend': trend,
        'confidence': confidence,
        'trend1': trend1,
        'trend2': trend2,
    }
```

## 5. 入场信号：自下而上

### 步骤 1：最低时间框架（15m/5m）寻找信号
```
用震荡指标：
  RSI < 30（超卖）→ 买入信号（主趋势向上时）
  RSI > 70（超买）→ 卖出信号（主趋势向下时）
```

### 步骤 2：向更高时间框架确认
```
15m 出现买入信号 → 检查 1h 是否支持
  1h RSI < 50 → 支持
  1h RSI > 50 → 不支持，等待
```

### 步骤 3：最高时间框架最终确认
```
1h 支持 → 检查 4h 趋势
  4h EMA50 > EMA200 → 最终确认，执行交易
```

### Python 实现：入场信号
```python
# multi_tf_entry.py
def find_entry_signal(candles_1h, candles_4h, trend):
    """
    寻找入场信号（自下而上）
    
    参数：
      candles_1h: 1h K 线
      candles_4h: 4h K 线
      trend: 主趋势（'UP' / 'DOWN'）
    
    返回：
      signal: 'BUY' / 'SELL' / None
      reason: 信号理由
    """
    from indicators import calc_rsi, calc_bollinger_bands, calc_ema
    
    # 1. 1h 信号
    closes_1h = [c['close'] for c in candles_1h]
    rsi_1h = calc_rsi(closes_1h, 14)
    bb_1h = calc_bollinger_bands(candles_1h, 20, 2.0)
    
    signal_1h = None
    if rsi_1h[-1] and bb_1h['lower'][-1]:
        if rsi_1h[-1] < 30 and closes_1h[-1] < bb_1h['lower'][-1]:
            signal_1h = 'BUY'
        elif rsi_1h[-1] > 70 and closes_1h[-1] > bb_1h['upper'][-1]:
            signal_1h = 'SELL'
    
    
    # 2. 4h 确认
    closes_4h = [c['close'] for c in candles_4h]
    ema50_4h = calc_ema(closes_4h, 50)
    ema200_4h = calc_ema(closes_4h, 200)
    
    if ema50_4h[-1] and ema200_4h[-1]:
        if trend == 'UP' and signal_1h == 'BUY':
            if ema50_4h[-1] > ema200_4h[-1]:
                return {
                    'signal': 'BUY',
                    'reason': '主趋势向上 + 1h 超卖 + 4h EMA 确认',
                }
        elif trend == 'DOWN' and signal_1h == 'SELL':
            if ema50_4h[-1] < ema200_4h[-1]:
                return {
                    'signal': 'SELL',
                    'reason': '主趋势向下 + 1h 超买 + 4h EMA 确认',
                }
    
    return {'signal': None, 'reason': '无入场信号'}
```

## 6. 冲突解决框架

### 冲突类型 1：趋势相反
```
日线：上涨趋势
4h：下跌趋势
  
解决：
  1. 信任更高时间框架（日线）
  2. 4h 下跌 = 回调，是买入机会
  3. 等待 4h RSI 超卖 + 价格到日线支撑位
```

### 冲突类型 2：指标矛盾
```
RSI：超卖（买入信号）
MACD：死叉（卖出信号）
  
解决：
  1. 看更高时间框架
  2. 如果日线趋势向上 → RSI 超卖优先（回调买入）
  3. 如果日线趋势向下 → MACD 死叉优先（反弹卖出）
```

### 冲突类型 3：时间框架信号冲突
```
日线：买入信号
1h：卖出信号
  
解决：
  1. 不交易（冲突）
  2. 等待更高时间框架信号确认
  3. 或降低仓位（50% 正常仓位）
```

### Python 实现：冲突检测
```python
# conflict_resolution.py
def detect_conflict(signals):
    """
    检测时间框架信号冲突
    
    参数：
      signals: {
        'weekly': 'BUY',
        'daily': None,
        '4h': 'SELL',
        '1h': 'SELL',
      }
    
    返回：
      conflict: True/False
      action: 'WAIT' / 'REDUCE_POSITION' / 'PROCEED'
    """
    # 检查最高和最低时间框架
    tf_order = ['weekly', 'daily', '4h', '1h']
    
    highest = None
    lowest = None
    
    for tf in tf_order:
        if signals.get(tf):
            lowest = signals[tf]
            break
    
    for tf in reversed(tf_order):
        if signals.get(tf):
            highest = signals[tf]
            break
    
    
    if highest and lowest and highest != lowest:
        # 冲突
        return {
            'conflict': True,
            'action': 'WAIT',
            'reason': f"最高框架 {highest} vs 最低框架 {lowest}",
        }
    elif highest and lowest and highest == lowest:
        # 一致
        return {
            'conflict': False,
            'action': 'PROCEED',
            'reason': f"所有框架一致: {highest}",
        }
    else:
        return {
            'conflict': False,
            'action': 'WAIT',
            'reason': '信号不足',
        }
```

## 7. Web3 独有：周期特性

### 特性 1：无开盘收盘 → 日线不精确
```
传统金融：
  日 K 线 = 今日开盘 → 今日收盘
  
Web3：
  日 K 线 = 过去 24h 数据
  → 没有"今日开盘"概念
  → 用 UTC 0:00 作为日 K 线分隔点
```

### 特性 2：周末不休市 → 波动率不同
```
传统金融：
  周一开盘：高波动（周末新闻积累）
  周五收盘：低波动（机构平仓）
  
Web3：
  周一～周日：波动率相对均匀
  但：周一亚洲时间（UTC 0:00-8:00）波动率较低
```

### 特性 3：美国时段影响最大
```
Web3 价格受美国时段影响最大：
  UTC 13:30-20:00（美股时间）→ 波动率最高
  UTC 0:00-8:00（亚洲时间）→ 波动率最低
  
调整：
  用美国时段（8h K 线）代替日线
  或：用 UTC 0:00 作为"日线"分隔
```

### Python 实现：Web3 时间框架调整
```python
# web3_timeframe_adjust.py
from datetime import datetime, timezone

def adjust_timeframe_for_web3(candles, target_tz='UTC'):
    """
    调整 Web3 时间框架（考虑 7x24 特性）
    
    参数：
      candles: K 线数据
      target_tz: 目标时区（'UTC' / 'US/Eastern'）
    
    返回：
      调整后的 K 线
    """
    adjusted = []
    
    for candle in candles:
        # 转换时区
        dt = datetime.fromtimestamp(candle['timestamp'] / 1000, tz=timezone.utc)
        
        if target_tz == 'US/Eastern':
            dt = dt.astimezone(timezone('US/Eastern'))
        
        
        # 重新分组（以美股开盘 9:30 AM EST 为日线分隔）
        if target_tz == 'US/Eastern':
            if dt.hour >= 9 and dt.minute >= 30:
                day_key = dt.strftime('%Y-%m-%d')
            else:
                # 前一天
                prev_day = dt - timedelta(days=1)
                day_key = prev_day.strftime('%Y-%m-%d')
        else:
            # UTC 0:00 作为分隔
            day_key = dt.strftime('%Y-%m-%d')
        
        
        # 聚合（简化）
        adjusted.append({
            **candle,
            'day_key': day_key,
        })
    
    
    # 重新聚合 K 线（按 day_key）
    # ...（略）
    
    return adjusted
```

## 8. 多时间框架指标合成

### 方法 1：投票制
```
日线 RSI：超卖 → 投票 +1
4h RSI：超卖 → 投票 +1
1h RSI：超卖 → 投票 +1
  
总分 ≥ 2 → 买入信号
总分 ≤ -2 → 卖出信号
```

### 方法 2：加权平均
```
日线信号（权重 0.5）+ 4h 信号（权重 0.3）+ 1h 信号（权重 0.2）
  
总分 > 0.6 → 买入
总分 < 0.4 → 卖出
```

### Python 实现：指标合成
```python
# multi_tf_combine.py
def combine_signals(signals, weights=None):
    """
    多时间框架信号合成
    
    参数：
      signals: {
        'daily': {'signal': 'BUY', 'strength': 0.8},
        '4h': {'signal': 'BUY', 'strength': 0.6},
        '1h': {'signal': None, 'strength': 0.0},
      }
      weights: {'daily': 0.5, '4h': 0.3, '1h': 0.2}
    
    返回：
      combined_signal: 'BUY' / 'SELL' / None
      score: 0.0-1.0
    """
    if weights is None:
        weights = {'daily': 0.5, '4h': 0.3, '1h': 0.2}
    
    
    score = 0.0
    
    for tf, signal_info in signals.items():
        signal = signal_info.get('signal')
        strength = signal_info.get('strength', 0.0)
        
        if signal == 'BUY':
            score += strength * weights.get(tf, 0.0)
        elif signal == 'SELL':
            score -= strength * weights.get(tf, 0.0)
        # None → 不计入
    
    
    if score > 0.6:
        combined_signal = 'BUY'
    elif score < -0.6:
        combined_signal = 'SELL'
    else:
        combined_signal = None
    
    
    return {
        'signal': combined_signal,
        'score': score,
        'details': {tf: s.get('signal') for tf, s in signals.items()},
    }
```

## 9. 代码模板

### 模板 1：完整多时间框架策略
```python
# multi_tf_strategy.py
import sys
sys.path.insert(0, 'scripts')

from indicators import calc_ema, calc_rsi, calc_bollinger_bands
from backtest import BacktestEngine

def multi_timeframe_strategy(symbol, daily_candles, h4_candles, h1_candles):
    """
    多时间框架策略
    
    逻辑：
      1. 日线判断趋势（EMA20/50/100）
      2. 4h 确认趋势（EMA50 > EMA200）
      3. 1h 寻找入场（RSI 超卖/超买 + 布林带）
    """
    # 1. 日线趋势
    daily_trend = detect_trend(
        daily_candles[-30:],  # 最近 30 根
        h4_candles[-120:],  # 最近 120 根（= 30 日 * 4）
        h1_candles[-720:],   # 最近 720 根（= 30 日 * 24）
    )
    
    
    # 2. 生成信号（与 1h K 线对齐）
    signals = [None] * len(h1_candles)
    
    for i in range(len(h1_candles)):
        # 只在主趋势方向上交易
        if daily_trend['trend'] == 'UP':
            # 寻找买入信号
            entry = find_entry_signal(
                h1_candles[max(0, i-24):i+1],
                h4_candles[max(0, i-6):i+1],
                trend='UP'
            )
            
            if entry['signal'] == 'BUY':
                signals[i] = 'BUY'
        
        elif daily_trend['trend'] == 'DOWN':
            # 寻找卖出信号
            entry = find_entry_signal(
                h1_candles[max(0, i-24):i+1],
                h4_candles[max(0, i-6):i+1],
                trend='DOWN'
            )
            
            if entry['signal'] == 'SELL':
                signals[i] = 'SELL'
    
    
    return signals

# 运行回测
if __name__ == '__main__':
    # 获取多时间框架数据
    daily = fetch_klines('BTCUSDT', interval='1d', limit=90)
```

```python
        h1,
        type='candle',
        mav=(20,),
        ax=axes[2],
        title='1h (Entry)',
    )

        if signal == 'BUY':
            axes[2].scatter(h1.index[i], h1['low'][i] * 0.999, color='green', marker='^')

            axes[2].scatter(h1.index[i], h1['high'][i] * 1.001, color='red', marker='v')
    
    
    plt.tight_layout()
    plt.show()
```

## 10. 总结与最佳实践

### 多时间框架分析速查表
| 步骤 | 时间框架 | 指标 | 目的 |
|------|---------|------|------|
| **1. 趋势判断** | 日线/周线 | EMA20/50/100 | 决定方向 |
| **2. 确认** | 4h | EMA50/200 | 确认趋势 |
| **3. 入场** | 1h | RSI + 布林带 | 寻找入场点 |
| **4. 精确入场** | 15m | K 线形态 | 优化止损 |

### 最佳实践
1. **永远看多周期**：不要只看 1 个时间框架
2. **更高时间框架优先**：日线 > 4h > 1h
3. **冲突时等待**：信号冲突 → 不交易
4. **Web3 调整**：用 UTC 0:00 或美股时间作为日线分隔
5. **回测多周期**：策略在日线/4h/1h 都要测试

### 常见错误
```
❌ 只看 1 个时间框架
❌ 忽略更高时间框架的趋势
❌ 在更高时间框架趋势相反时交易
❌ 用低时间框架信号覆盖高时间框架信号
```
