## 一、核心链上指标

### 1. MVRV Z-Score（估值指标）

**公式**：
```
MVRV Z-Score = (Market Value - Realized Value) / Standard Deviation
```

**解读**：
| Z-Score | 市场状态 | 操作建议 |
|----------|-----------|-----------|
| > 3 | 严重高估（顶部） | 减仓/清仓 |
| 2-3 | 偏高 | 谨慎/减仓 |
| 0-2 | 正常 | 持有 |
| -0.5-0 | 偏低 | 可买入 |
| < -0.5 | 严重低估（底部） | 加仓 |

**数据源**：Glassnode API (`indicators/mvrv_z_score`)

---

### 2. SOPR（支出产出利润率）

**公式**：
```
SOPR = 卖出价格 / 买入价格
```

**解读**：
- `SOPR > 1`：盈利卖出（市场乐观）
- `SOPR < 1`：亏损卖出（市场悲观）
- `SOPR = 1`：盈亏平衡

**交易信号**：
- SOPR < 1 且反弹 → 买入信号（恐慌底）
- SOPR > 1.05 且回落 → 卖出信号（贪婪顶）

**数据源**：Glassnode API (`indicators/sopr`)

---

### 3. 交易所净流（资金动向）

**公式**：
```
净流 = 流入 - 流出
```

**解读**：
- `净流 < 0`（流出 > 流入）→ 看涨信号（筹码从交易所转出，减少抛压）
- `净流 > 0`（流入 > 流出）→ 看跌信号（筹码转入交易所，增加抛压）

**数据源**：Glassnode API (`exchanges/netflow_total`)

---

### 4. 稳定币市值（流动性指标）

**意义**：
- 稳定币市值 ↑ → 市场流动性充足（上涨动力）
- 稳定币市值 ↓ → 市场流动性收缩（下跌风险）

**数据源**：Glassnode API (`stablecoins/marketcap`)

## 四、Glassnode API 使用指南

### 1. 认证

```python
API_KEY = 'your_glassnode_api_key'
BASE_URL = 'https://api.glassnode.com/api/v1'
```

### 2. 常用端点

| 指标 | 端点 | 说明 |
|------|-------|------|
| 价格 | `market/price_usd` | BTC/ETH 美元价格 |
| MVRV | `indicators/mvrv_z_score` | 估值指标 |
| SOPR | `indicators/sopr` | 支出产出利润率 |
| 交易所净流 | `exchanges/netflow_total` | 资金流向 |
| 活跃地址 | `addresses/active_count` | 网络活跃度 |

### 3. 示例代码

```python
import requests

def fetch_glassnode(metric, asset='BTC', interval='24h', api_key=API_KEY):
    url = f'{BASE_URL}/{metric}'
    params = {
        'a': asset,
        'i': interval,
        'api_key': api_key,
    }
    response = requests.get(url, params=params)
    return response.json()

# 获取 MVRV Z-Score
data = fetch_glassnode('indicators/mvrv_z_score', asset='BTC')
print(f"最新 MVRV Z-Score: {data[-1]['v']:.2f}")
```
