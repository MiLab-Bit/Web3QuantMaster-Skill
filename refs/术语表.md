# 币圈术语表

> 入门必备 + 进阶实战手册，区分"知道"与"做到"

---

## 一、基础概念（必须掌握）

| 术语 | 解释 | 实操要点 |
|------|------|---------|
| **现货（Spot）** | 当下实际持有币种，随时可卖 | 最安全，无归零风险（除非归零） |
| **合约（Futures）** | 约定未来价格，可做多做空 | 带杠杆，有爆仓风险，新手慎入 |
| **杠杆（Leverage）** | 借资金放大本金 | 10x杠杆 = 10倍波动，1万变10万用 |
| **做多（Long）** | 买入等涨，低买高卖 | 最直觉的赚钱方式 |
| **做空（Short）** | 借币卖出等跌，高卖低买 | 熊市工具，新手容易亏 |
| **爆仓（Liquidation）** | 保证金不足被强平，本金归零 | 币圈最常见的死亡方式 |
| **滑点（Slippage）** | 成交价与预期价的差 | 大涨大跌时滑点可吃掉3-5%利润 |

## 二、K线核心术语（图解级理解）

### 基础形态

| 术语 | 说明 | 实战含义 |
|------|------|---------|
| **阳线** | 收盘>开盘，币圈绿色 | 多方占优，但可能是假的 |
| **阴线** | 收盘<开盘，币圈红色 | 空方占优，但可能是诱空 |
| **十字星** | 开盘≈收盘 | 犹豫信号，通常不是入场时机 |
| **锤子线** | 下影线>实体×2，实体在上部 | 底部反转信号，需配合量能确认 |
| **上吊线** | 上影线>实体×2，实体在下部 | 顶部反转信号，高位出现要小心 |
| **吞没形态** | 后一根K线实体完全包裹前一根 | 强反转信号，量能越大越有效 |
| **早晨之星** | 两阴夹一阳中间的阳线 | 底部三合一信号，胜率较高 |
| **黄昏之星** | 两阳夹一阴中间的阴线 | 顶部三合一信号，高位出现必警惕 |

### 趋势线

| 术语 | 说明 | 实战含义 |
|------|------|---------|
| **支撑位** | 买方集中的价格，跌到这里容易反弹 | 不是铁底，只是减速带 |
| **阻力位** | 卖方集中的价格，涨到这里容易回落 | 可以被放量突破 |
| **突破** | 价格穿越阻力/支撑 | 缩量突破80%是假的 |
| **回踩** | 突破后价格回到原阻力位确认 | 回踩不破=真突破，最佳入场点 |
| **盘整** | 价格在一个区间内反复 | 横有多长，竖有多高（也可能久横必跌） |

## 三、交易核心术语

| 术语 | 解释 | 致命陷阱 |
|------|------|---------|
| **止损（Stop Loss）** | 亏损到预设位置自动割肉 | 不设=慢性自杀 |
| **止盈（Take Profit）** | 盈利到目标自动卖出 | 贪心不止盈=过山车 |
| **追踪止损** | 涨多少就上移止损线 | 让利润奔跑的唯一方法 |
| **市价单** | 按当前价格立即成交 | 大单慎用，可能滑点3%+ |
| **限价单** | 设定价格等成交 | 挂高了不成交，白等 |
| **挂单（Maker）** | 挂单等人成交（手续费低） | 不成交=不赚钱 |
| **吃单（Taker）** | 直接成交别人挂的单（手续费高） | 追涨杀跌都是吃单 |
| **流动性** | 买卖盘深度 | 深度差的山寨币可能卖不出 |
| **未平仓合约（OI）** | 市场上当前持有的合约总量 | OI暴涨=多空对赌，可能爆一边 |
| **资金费率（Funding Rate）** | 多空双方互相付的费 | 持续正向=多头被收费=做空信号 |

## 四、风控核心术语

| 术语 | 解释 | 操作规范 |
|------|------|---------|
| **最大回撤** | 从最高点到最低点最大跌幅 | 实盘必须控制在20%以内 |
| **夏普比率（Sharpe）** | 收益/风险的比值 | >1.0算合格，>2.0优秀 |
| **胜率** | 赚钱次数/总交易次数 | 胜率50%不等于赚钱 |
| **盈亏比** | 平均盈利/平均亏损 | 盈亏比2:1，胜率40%就能赚钱 |
| **爆仓线** | 保证金能承受的最大亏损 | 合约仓位计算好再开 |
| **保证金率** | 保证金/合约价值的比例 | 低于100%即强平 |

## 五、合约专业术语

| 术语 | 解释 | 实战注意 |
|------|------|---------|
| **全仓模式** | 所有资金共用保证金 | 一个仓爆=全仓爆 |
| **逐仓模式** | 每个仓位独立保证金 | 推荐，防止连环爆 |
| **强平价** | 触发强平的合约价格 | 开仓前必须算好 |
| **自动追加保证金** | 亏损时自动转入保证金 | 防止被秒爆，但可能亏更多 |
| **穿仓** | 爆仓后还倒欠交易所钱 | 国内交易所少见，OKX/Bybit有 |
| **溢价** | 合约价格 > 现货价格 | 正溢价=看多情绪，负溢价=看空 |

## 六、DeFi核心术语

| 术语 | 解释 | 风险提示 |
|------|------|---------|
| **TVL** | 锁仓量，总共存入协议多少钱 | TVL高≠安全，可能是土狗池 |
| **流动性池** | 用来交易的资金池 | 池子小=滑点大=亏钱 |
| **AMM** | 自动做市商，按公式定价 | 无常损失是隐形杀手 |
| **无常损失（IL）** | 提供流动性导致的机会成本损失 | LP年化30%可能补不回IL |
| **流动性挖矿** | 提供流动性换取代币奖励 | 代币可能是空气 |
| **质押（Staking）** | 锁币吃利息 | 锁定期内无法卖出 |
| **借贷协议** | 存币借币（如Aave） | 超额抵押是基本要求 |
| **预言机** | 把链外数据传上链 | 数据被操纵=清算风险 |

## 七、链上数据术语

| 术语 | 解释 | 实战用法 |
|------|------|---------|
| **MVRV** | 市值/已实现价值 | <1.5=低估，>3.5=高估 |
| **SOPR** | 已实现利润/亏损比率 | >1=整体盈利状态=潜在卖压 |
| **NUPL** | 未实现净损益 | >0.75=极度贪婪=见顶信号 |
| **RHODL** | RHODL比率 | 历史极高值=市场顶部 |
| **STH-MVRV** | 短期持有者成本基础 | BTC<1=短期持有者被套=见底信号 |
| **交易所余额** | 交易所控制的BTC数量 | 余额下降=持币不卖=潜在利好 |
| **矿工余额** | 矿工钱包的余额 | 矿工抛售=短期压力 |

## 八、必须掌握的交易原则

### 铁律（必须100%遵守）

```
1. 【不止损，勿开仓】 - 不设止损就等于赌博
2. 【不满仓，留子弹】 - 满仓遇到瀑布无法补仓
3. 【不合约赌身家】 - 合约只是对冲工具，不是提款机
4. 【不追涨杀跌】 - 追进去的是行情末尾，割出来的是起涨前
5. 【不重仓单一币】 - 山寨归零概率比你想象的高
```

### 常见错误对照表

| 错误操作 | 当时心理 | 实际结果 |
|---------|---------|---------|
| 亏损后不止损 | "还会涨回来的" | -50% → -80% → 套牢 |
| 盈利后加仓 | "赚更多" | 回调被吞掉所有利润 |
| 频繁止损 | "小亏是风控" | 连续止损消耗本金 |
| 全仓梭哈 | "这次一定" | 归零风险，一次就够了 |
| 看到大阳线买入 | FOMO | 追在最高点 |
| 看到大阴线卖出 | 恐慌 | 割在最低点 |
| 参考别人的喊单操作 | 抄作业 | 庄家出货你接盘 |
| 持有多个同类币种 | "分散风险" | 山寨同涨同跌，没分散 |

## 九、市场结构认知

### 币圈周期特征

```
机构主导期（BTC ETF后）：跟美股高度相关，宏观驱动
散户主导期（牛市中后期）：土狗横行，FOMO情绪
庄家主导期（熊市）：控盘严重，拉盘砸盘频繁
矿工主导期（减半前后）：卖压主导，成本支撑
```

### 价格运动的三种模式

| 模式 | 特征 | 应对策略 |
|------|------|---------|
| **趋势（Trend）** | 高点高点抬高，低点低点抬高 | 顺势，回调入场 |
| **震荡（Range）** | 高点接近，低点接近 | 区间高卖低买 |
| **突破（Breakout）** | 突破震荡区间 | 等回踩确认再入 |

### 量的语言

```
放量上涨 = 真涨，继续持有
放量下跌 = 真跌，谨慎
缩量上涨 = 虚涨，可能是顶部
缩量下跌 = 可能见底（卖不动了）
突然放量 = 主力异动，追不追要看位置
```
