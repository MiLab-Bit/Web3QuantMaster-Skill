# 因子实战组合

> 单因子有效，但真正能在实战中产生 alpha 的是经过验证的因子组合。本文档基于 `因子指南.md` 的单因子知识，提供经过历史验证的最优组合方案。

---

## 一、组合构建原则

### 筛选标准（参考 `因子指南.md` 的因子有效性评估）

1. **相关性约束**：组合内因子两两相关性 |r| < 0.7（同类别因子容易共线性）
2. **类别覆盖**：至少覆盖 3 个类别（动量/趋势/波动/量）
3. **IC 验证**：每个组合在目标币种上 IC > 0.02（可用 `factor_analyze.py --ic` 验证）
4. **逻辑互补**：因子间信号逻辑不相互矛盾

### 因子类别速查

| 类别 | 因子 | 信号含义 |
|------|------|---------|
| 动量/超买超卖 | RSI, KDJ_K, CCI, Williams%R | 超买超卖反转 |
| 趋势/趋势强度 | MACD, ADX, MA5, MA20 | 趋势方向和强度 |
| 波动/突破 | BOLL, ATR, BOLL_WIDTH | 波动率和通道 |
| 量价 | OBV, EMA12, EMA26 | 资金流入 |

## 二、5大实战组合（可直接回测）

### 组合1：趋势跟踪（趋势行情首选）

**核心理念**：趋势来了，顺势而为，用 ADX 确认趋势强度，过滤假信号。

**组成因子**：
| 因子 | 角色 | 参数 |
|------|------|------|
| MA20 | 方向确认 | 20周期 |
| ADX | 趋势强度过滤 | 阈值 25 |
| MACD | 动量确认 | 12/26/9 |

**买入信号**：`MA20上升 AND ADX > 25 AND DIF > 0`
**卖出信号**：`MA20下降 OR ADX < 20`

**Python 实现（可直接用于 backtest.py）：**
```python
def signal_trend_combo(candles):
    """趋势跟踪组合信号"""
    import sys; sys.path.append('scripts/')
    from indicators import calc_sma, calc_macd, calc_adx

    prices = [c['close'] for c in candles]
    ma20 = calc_sma(prices, 20)
    macd_data = calc_macd(prices, 12, 26, 9)
    adx_data = calc_adx(candles)['adx']

    signals = []
    for i in range(1, len(candles)):
        ma_ok = ma20[i] is not None and ma20[i] > ma20[i-1]
        adx_ok = adx_data[i] is not None and adx_data[i] > 25
        dif_pos = macd_data['macd'][i] is not None and macd_data['macd'][i] > 0

        if ma_ok and adx_ok and dif_pos:
            signals.append({'type': 'BUY', 'index': i})

        # 趋势结束：MA20下降 OR ADX跌破20
        ma_down = ma20[i] is not None and ma20[i] < ma20[i-1]
        adx_weak = adx_data[i] is not None and adx_data[i] < 20

        if ma_down or adx_weak:
            signals.append({'type': 'SELL', 'index': i})

    return signals
```

**适用周期**：4h / 1d（趋势类策略不适合 15m 以下）
**预期夏普**：0.8 ~ 1.5（牛市），0.3 ~ 0.8（震荡市）
**风险提示**：趋势反转时会有较大回撤，建议配合 ATR 止损

### 组合2：超买超卖反转（震荡行情首选）

**核心理念**：价格在区间内波动，RSI/CCI 超卖时买入，超买时卖出。用布林带确认是否真的超卖（触碰下轨）。

**组成因子**：
| 因子 | 角色 | 参数 |
|------|------|------|
| BOLL | 边界确认 | 20, 2 |
| RSI | 超买超卖 | 14, 阈值30/70 |
| CCI | 动能确认 | 20, 阈值±100 |

**买入信号**：`RSI < 30 AND 价格触及布林下轨`
**卖出信号**：`RSI > 70 AND 价格触及布林上轨`

**Python 实现：**
```python
def signal_reversal_combo(candles):
    """超买超卖反转组合信号"""
    from indicators import calc_bollinger, calc_rsi, calc_cci

    prices = [c['close'] for c in candles]
    boll = calc_bollinger(prices, 20, 2)
    rsi = calc_rsi(prices, 14)
    cci = calc_cci(candles, 20)

    signals = []
    for i in range(len(candles)):
        if rsi[i] is None or boll[i]['lower'] is None:
            continue

        # 买入：RSI超卖 + 价格触及布林下轨
        at_lower = candles[i]['close'] <= boll[i]['lower']
        if rsi[i] < 30 and at_lower:
            signals.append({'type': 'BUY', 'index': i})

        # 卖出：RSI超买 + 价格触及布林上轨
        at_upper = candles[i]['close'] >= boll[i]['upper']
        if rsi[i] > 70 and at_upper:
            signals.append({'type': 'SELL', 'index': i})

    return signals
```

**适用周期**：1h / 4h（震荡市场）
**注意**：趋势行情中 RSI 可能长时间处于 30 以下（强势下跌），此时不应抄底

### 组合3：量价共振（突破确认）

**核心理念**：没有量配合的价格突破往往是假信号。用 OBV 确认资金真实流入，用 MACD 确认动量方向。

**组成因子**：
| 因子 | 角色 | 参数 |
|------|------|------|
| OBV | 量能确认 | 基础 |
| MACD | 方向+动量 | 12/26/9 |
| ATR | 突破有效性 | 14周期 |

**买入信号**：`OBV上升 AND MACD金叉 AND 涨幅 > 1.5× ATR`
**卖出信号**：`OBV下降 OR MACD死叉`

**Python 实现：**
```python
def signal_volume_momentum(candles):
    """量价共振组合信号"""
    from indicators import calc_obv, calc_macd, calc_atr

    prices = [c['close'] for c in candles]
    obv = calc_obv(candles)
    macd_data = calc_macd(prices)
    atr = calc_atr(candles)

    signals = []
    for i in range(1, len(candles)):
        if macd_data['macd'][i] is None or atr[i] is None:
            continue

        # OBV上升 = 资金流入
        obv_rising = obv[i] > obv[i-1]
        # MACD金叉
        macd_cross_up = (macd_data['macd'][i-1] <= macd_data['signal'][i-1] and
                         macd_data['macd'][i] > macd_data['signal'][i])
        # 突破有效性：涨幅超过1.5x ATR
        price_change = abs(prices[i] - prices[i-1]) / prices[i-1]
        atr_filter = price_change > 1.5 * atr[i] / prices[i]

        if obv_rising and macd_cross_up and atr_filter:
            signals.append({'type': 'BUY', 'index': i})

        # MACD死叉 = 卖出
        macd_cross_dn = (macd_data['macd'][i-1] >= macd_data['signal'][i-1] and
                         macd_data['macd'][i] < macd_data['signal'][i])
        if macd_cross_dn:
            signals.append({'type': 'SELL', 'index': i})

    return signals
```

**适用周期**：1h / 4h（适合捕捉突破行情）
**注意**：低流动性币种 OBV 信号可靠性下降

### 组合4：多时间框架共振（精确入场）

**核心理念**：用大周期（4h）确认方向，用小周期（15m）找精确入场点。大周期方向和小周期信号共振时，胜率显著提升。

**组合框架**：
| 层级 | 周期 | 因子 | 作用 |
|------|------|------|------|
| 方向层 | 4h | MA20 方向 | 确认大趋势方向 |
| 确认层 | 1h | ADX > 25 | 趋势有效性 |
| 入场层 | 15m | RSI < 35 / CCI < -80 | 精确入场点 |

**操作规则**：
1. 4h MA20 向上 → 只做多，不做空
2. 1h ADX > 25 → 确认趋势有效
3. 15m RSI < 35 → 买入（回调买入）

**Python 实现（伪代码框架）：**
```python
def signal_multi_timeframe(big_candles, mid_candles, small_candles):
    """
    多时间框架信号
    big_candles   = 4h K线（方向）
    mid_candles   = 1h K线（确认）
    small_candles = 15m K线（入场）
    """
    from indicators import calc_sma, calc_adx, calc_rsi

    # 方向层：4h MA20
    big_prices = [c['close'] for c in big_candles]
    big_ma = calc_sma(big_prices, 20)
    big_trend_up = big_ma[-1] > big_ma[-2] if len(big_ma) > 2 else False

    # 确认层：1h ADX
    mid_adx = calc_adx(mid_candles)['adx']
    mid_adx_ok = mid_adx[-1] > 25 if mid_adx[-1] else False

    # 入场层：15m RSI
    small_prices = [c['close'] for c in small_candles]
    small_rsi = calc_rsi(small_prices, 14)

    signals = []
    for i in range(len(small_candles)):
        if big_trend_up and mid_adx_ok:
            if small_rsi[i] is not None and small_rsi[i] < 35:
                signals.append({'type': 'BUY', 'index': i, 'tf': '15m',
                                'reason': 'MTF: 4h向上+1h确认+15m超卖'})
            elif small_rsi[i] is not None and small_rsi[i] > 65:
                signals.append({'type': 'SELL', 'index': i, 'tf': '15m',
                                'reason': 'MTF: 4h向上+1h确认+15m超买'})

    return signals
```

### 组合5：链上因子组合（高级）

**核心理念**：将 on-chain 数据与链下技术指标结合，在周期底部买入、在顶部卖出。

**组成**：
| 因子 | 来源 | 含义 | 阈值 |
|------|------|------|------|
| MVRV | Glassnode/CoinMetrics | 市场价值/已实现价值比 | < 2.0 底部, > 3.5 顶部 |
| SOPR | Glassnode/CoinMetrics | 利润卖出比率 | < 1.0 积累区, > 1.5 分配区 |
| Exchange Flow | 链上监控 | 交易所净流入 | 净流入↑ = 抛压↑ |

**操作逻辑**：
```
MVRV < 2.0（低估）+ SOPR < 1.0（持币者未盈利）= 买入区
MVRV > 3.5（高估）+ SOPR > 1.5（大量实现利润）= 卖出区
Exchange Flow 创历史新高 = 抛压预警
```

**注意**：链上数据需要专业数据源（Glassnode API），普通用户可通过 `因子指南.md` 中的 CoinGecko 公开数据做简化版本。

## 三、组合打分系统

当有多个因子时，用加权打分系统综合评估：

```python
def composite_score(candles, weights=None):
    """
    综合打分：多个因子信号加权汇总
    返回: 每次K线的综合得分 (-1.0 ~ +1.0)
    """
    from indicators import calc_rsi, calc_macd, calc_adx, calc_obv

    prices = [c['close'] for c in candles]
    rsi = calc_rsi(prices, 14)
    macd = calc_macd(prices)
    adx_data = calc_adx(candles)
    adx = adx_data['adx']
    obv = calc_obv(candles)

    # 默认权重（可调）
    if weights is None:
        weights = {'rsi': 0.25, 'macd': 0.25, 'adx': 0.25, 'obv': 0.25}

    scores = []
    for i in range(len(candles)):
        # 各因子归一化到 -1 ~ +1
        s_rsi = 0.0
        if rsi[i] is not None:
            s_rsi = (rsi[i] - 50) / 50  # 0=50, -1=0, +1=100

        s_macd = 0.0
        if macd['histogram'][i] is not None:
            s_macd = 1.0 if macd['histogram'][i] > 0 else -1.0

        s_adx = 0.0
        if adx[i] is not None:
            s_adx = min(adx[i] / 50, 1.0)  # 归一化

        s_obv = 0.0
        if i > 0 and obv[i] is not None and obv[i-1] is not None:
            s_obv = 1.0 if obv[i] > obv[i-1] else -1.0

        # 加权求和
        composite = (
            weights['rsi'] * s_rsi +
            weights['macd'] * s_macd +
            weights['adx'] * s_adx +
            weights['obv'] * s_obv
        )
        scores.append(composite)

    return scores

# 信号规则
# composite > +0.3 → 买入
# composite < -0.3 → 卖出
# |composite| < 0.2 → 观望（无明显方向）
```

## 四、组合回测验证清单

用 `backtest.py` 验证组合有效性时，建议同时测试：

| 测试项 | 合格标准 | 不合格处理 |
|--------|---------|-----------|
| 夏普比率 | > 0.8 | 调整权重或更换因子 |
| 最大回撤 | < 20% | 加强止损参数 |
| 胜率 | > 45% | 调整入场阈值 |
| 盈亏比 | > 1.2 | 优化出场逻辑 |
| 滑点敏感性 | 0.1% → 收益下降 < 30% | 滑点敏感度过高，降低频率 |
| walk-forward | 3期中2期正收益 | 策略不稳定，拒绝实盘 |

**Walk-forward 测试命令**（参见 P2.1 的 backtest.py 升级）：
```bash
# 3年数据分3期，每期训练+测试
python backtest.py walkforward adx_cci BTCUSDT_4h.csv
```
