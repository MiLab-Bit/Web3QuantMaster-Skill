## 1. 收益指标

### 1.1 总收益率（Total Return）
```
TR = (终值 - 初值) / 初值
```

### 1.2 年化收益率（CAGR）
```
CAGR = (终值 / 初值)^(1/年数) - 1
```

### 1.3 平均单笔收益（Average Trade Return）
```
ATR = 总收益 / 交易次数
```

### Python 实现
```python
# returns.py
import numpy as np
import pandas as pd

def calculate_returns(equity_curve):
    """
    计算收益指标
    
    参数：
      equity_curve: 权益曲线 [10000, 10200, ..., 15000]
    
    返回：指标字典
    """
    equity = np.array(equity_curve)
    
    # 总收益率
    total_return = (equity[-1] - equity[0]) / equity[0]
    
    # 年化收益率（假设 252 个交易日）
    days = len(equity) / 252  # 年数
    cagr = (equity[-1] / equity[0]) ** (1 / days) - 1
    
    # 平均单笔收益
    daily_returns = np.diff(equity) / equity[:-1]
    avg_daily_return = np.mean(daily_returns)
    
    return {
        'total_return': total_return,
        'cagr': cagr,
        'avg_daily_return': avg_daily_return,
        'final_equity': equity[-1],
    }
```

## 2. 风险指标

### 2.1 最大回撤（Max Drawdown）
```
MDD = max((峰值 - 谷值) / 峰值)
```

### 2.2 回撤持续时间（Drawdown Duration）
```
从峰值到新峰值的时间
```

### 2.3 下行波动率（Downside Volatility）
```
DV = std(负收益)
  与总体波动率不同，只关注下行
```

### 2.4 VaR（Value at Risk）
```
VaR(95%) = 5% 分位数
含义：95% 概率下，单日损失不超过 VaR
```

### 2.5 CVaR（Conditional VaR）
```
CVaR = 超过 VaR 的那部分收益的平均值
比 VaR 更关注尾部风险
```

### Python 实现
```python
# risk_metrics.py
def calculate_risk_metrics(equity_curve, confidence=0.95):
    """
    计算风险指标
    """
    equity = np.array(equity_curve)
    daily_returns = np.diff(equity) / equity[:-1]
    
    # 最大回撤
    peak = np.maximum.accumulate(equity)
    drawdown = (equity - peak) / peak
    max_dd = abs(min(drawdown))
    
    # 回撤持续时间
    dd_start = np.argmax(equity)
    dd_end = np.argmin(equity[dd_start:]) + dd_start
    dd_duration = dd_end - dd_start
    
    # 下行波动率
    downside_returns = daily_returns[daily_returns < 0]
    downside_vol = np.std(downside_returns) * np.sqrt(252)  # 年化
    
    # VaR
    var = np.percentile(daily_returns, (1 - confidence) * 100)
    
    # CVaR
    cvar = np.mean(daily_returns[daily_returns <= var])
    
    return {
        'max_drawdown': max_dd,
        'dd_duration': dd_duration,
        'downside_vol': downside_vol,
        f'var_{int(confidence*100)}': var,
        f'cvar_{int(confidence*100)}': cvar,
    }
```

## 3. 风险调整收益指标

### 3.1 夏普比率（Sharpe Ratio）
```
SR = (E[R] - Rf) / σ
  Rf: 无风险利率（美债 ~5%）
  σ: 总体波动率（年化）
```

**解读**：
| SR | 评价 |
|----|------|
| < 0 | 亏损 |
| 0-1 | 差 |
| 1-2 | 良好 |
| 2-3 | 优秀 |
| > 3 | 卓越（警惕过拟合） |

### 3.2 索提诺比率（Sortino Ratio）
```
Sortino = (E[R] - Rf) / Downside Volatility
  与夏普区别：只关注下行波动率
```

### 3.3 卡玛比率（Calmar Ratio）
```
Calmar = CAGR / Max Drawdown
  比夏普更关注最大回撤
```

### 3.4 欧米伽比率（Omega Ratio）
```
Omega = (E[正收益]) / (|E[负收益]|)
  考虑整个收益分布，不只是均值/方差
```

### Python 实现
```python
# risk_adjusted_returns.py
def calculate_risk_adjusted(equity_curve, risk_free_rate=0.05):
    """
    计算风险调整收益指标
    """
    equity = np.array(equity_curve)
    daily_returns = np.diff(equity) / equity[:-1]
    
    # 年化收益率
    days = len(equity) / 252
    cagr = (equity[-1] / equity[0]) ** (1 / days) - 1
    
    # 年化波动率
    annual_vol = np.std(daily_returns) * np.sqrt(252)
    
    # 夏普比率
    sharpe = (cagr - risk_free_rate) / annual_vol if annual_vol > 0 else 0.0
    
    # 索提诺比率
    downside_vol = np.std(daily_returns[daily_returns < 0]) * np.sqrt(252)
    sortino = (cagr - risk_free_rate) / downside_vol if downside_vol > 0 else 0.0
    
    # 卡玛比率
    peak = np.maximum.accumulate(equity)
    drawdown = (equity - peak) / peak
    max_dd = abs(min(drawdown))
    calmar = cagr / max_dd if max_dd > 0 else 0.0
    
    # 欧米伽比率
    positive_returns = daily_returns[daily_returns > 0]
    negative_returns = daily_returns[daily_returns < 0]
    omega = np.mean(positive_returns) / abs(np.mean(negative_returns)) if len(negative_returns) > 0 else np.inf
    
    return {
        'sharpe': sharpe,
        'sortino': sortino,
        'calmar': calmar,
        'omega': omega,
    }
```

## 4. 交易行为指标

### 4.1 胜率（Win Rate）
```
WR = 盈利交易数 / 总交易数
```

### 4.2 盈亏比（Profit Factor）
```
PF = 总盈利 / |总亏损|
  PF > 1.5 → 良好
  PF < 1.0 → 亏损
```

### 4.3 期望收益（Expected Payoff）
```
EP = (胜率 × 平均盈利) + ((1-胜率) × 平均亏损)
```

### 4.4 最大连续盈利/亏损笔数
```
检测策略是否"过热"或"失效"
```

### Python 实现
```python
# trading_behavior.py
def calculate_trading_behavior(trade_pnls):
    """
    计算交易行为指标
    
    参数：
      trade_pnls: 每笔交易的盈亏列表 [123.4, -56.7, 89.1, ...]
    """
    pnls = np.array(trade_pnls)
    
    # 胜率
    wins = pnls[pnls > 0]
    losses = pnls[pnls < 0]
    win_rate = len(wins) / len(pnls) if len(pnls) > 0 else 0.0
    
    # 盈亏比
    profit_factor = abs(wins.sum() / losses.sum()) if len(losses) > 0 else np.inf
    
    # 期望收益
    expected_payoff = (win_rate * wins.mean()) + ((1 - win_rate) * losses.mean()) if len(losses) > 0 else wins.mean()
    
    # 最大连续盈利/亏损
    from itertools import groupby
    sign = np.sign(pnls)
    max_win_streak = max(len(list(g)) for k, g in groupby(sign) if k > 0) if any(sign > 0) else 0
    max_loss_streak = max(len(list(g)) for k, g in groupby(sign) if k < 0) if any(sign < 0) else 0
    
    return {
        'win_rate': win_rate,
        'profit_factor': profit_factor,
        'expected_payoff': expected_payoff,
        'max_win_streak': max_win_streak,
        'max_loss_streak': max_loss_streak,
    }
```

## 5. 稳健性检验

### 5.1 敏感性分析（Sensitivity Analysis）
```
测试参数微小变化对结果的影响：
  参数 +1% → 收益变化 < 5% → 稳健
  参数 +1% → 收益变化 > 20% → 脆弱（过拟合）
```

### 5.2 子样本分析（Sub-sample Analysis）
```
将样本分为 3 段：
  训练集（60%）→ 优化参数
  验证集（20%）→ 选择参数
  测试集（20%）→ 最终评估
```

### 5.3 蒙特卡洛模拟（Monte Carlo）
```
随机打乱交易顺序，重复 1000 次：
  原策略收益 > 95% 随机序列 → 策略有效
  原策略收益 < 50% 随机序列 → 策略无效（运气）
```

### 5.4  Walk-Forward 分析
```
滚动窗口优化：
  第 1 年：优化 → 第 2 年：测试
  第 2 年：优化 → 第 3 年：测试
  ...
```

### Python 实现：蒙特卡洛模拟
```python
# monte_carlo.py
import numpy as np
from tqdm import tqdm

def monte_carlo_test(trade_pnls, n_simulations=1000):
    """
    蒙特卡洛模拟测试策略稳健性
    
    参数：
      trade_pnls: 原策略的每笔交易盈亏
      n_simulations: 模拟次数
    
    返回：
      p_value: 原策略收益排名 / 总模拟次数
    """
    original_total = sum(trade_pnls)
    
    simulated_totals = []
    for _ in tqdm(range(n_simulations), desc="Monte Carlo"):
        # 随机打乱交易顺序
        shuffled = np.random.permutation(trade_pnls)
        simulated_total = shuffled.sum()
        simulated_totals.append(simulated_total)
    
    # 计算 p-value
    p_value = sum(1 for s in simulated_totals if s >= original_total) / n_simulations
    
    return {
        'original_total': original_total,
        'p_value': p_value,
        'significant': p_value < 0.05,  # 5% 显著性水平
    }
```

```python
# walk_forward.py
def walk_forward_analysis(strategy_func, data, window_size=252, step_size=63):
    """
    Walk-Forward 分析
    
    参数：
      strategy_func: 策略函数（接收数据和参数，返回收益）
      data: 全部数据
      window_size: 优化窗口（交易日数）
      step_size: 测试步长
    
    返回：
      oos_results: 样本外结果列表
    """
    oos_results = []
    
    for start in range(0, len(data) - window_size - step_size, step_size):
        # 优化窗口
        opt_data = data[start:start+window_size]
        
        # 优化参数（简化：网格搜索）
        best_params = optimize_params(strategy_func, opt_data)
        
        # 测试窗口（样本外）
        test_data = data[start+window_size:start+window_size+step_size]
        test_return = strategy_func(test_data, best_params)
        
        oos_results.append({
            'period_start': start,
            'period_end': start+window_size+step_size,
            'params': best_params,
            'oos_return': test_return,
        })
    
    # 汇总
    avg_oos_return = np.mean([r['oos_return'] for r in oos_results])
    consistency = sum(1 for r in oos_results if r['oos_return'] > 0) / len(oos_results)
    
    return {
        'oos_results': oos_results,
        'avg_oos_return': avg_oos_return,
        'consistency': consistency,  # > 0.6 → 稳健
    }
```

## 6. 样本外测试（Out-of-Sample）

### 为什么要做 OOS 测试？
```
训练集表现很好，但测试集表现差 → 过拟合
```

### OOS 测试框架
```
1. 将数据分为训练集（70%）和测试集（30%）
2. 在训练集上优化参数
3. 在测试集上测试（不重新优化）
4. 比较训练集和测试集的表现差异
```

### 判断标准
| 指标 | 训练集 | 测试集 | 判断 |
|------|--------|--------|------|
| 夏普比率 | 2.5 | 2.1 | ✅ 稳健（差异 < 20%） |
| 夏普比率 | 2.5 | 0.8 | ❌ 过拟合（差异 > 50%） |

### Python 实现
```python
# oos_test.py
def oos_test(strategy_func, data, train_ratio=0.7):
    """
    样本外测试
    
    参数：
      strategy_func: 策略函数
      data: 全部数据
      train_ratio: 训练集比例
    
    返回：
      训练集和测试集的表现对比
    """
    split_idx = int(len(data) * train_ratio)
    
    train_data = data[:split_idx]
    test_data = data[split_idx:]
    
    # 在训练集上优化
    best_params = optimize_params(strategy_func, train_data)
    
    # 在训练集上测试（样本内）
    train_return = strategy_func(train_data, best_params)
    
    # 在测试集上测试（样本外）
    test_return = strategy_func(test_data, best_params)
    
    # 比较
    degradation = (train_return - test_return) / train_return
    
    return {
        'best_params': best_params,
        'train_return': train_return,
        'test_return': test_return,
        'degradation': degradation,
        'robust': degradation < 0.2,  # 退化 < 20% → 稳健
    }
```

## 7. 过拟合检测

### 7.1 参数数量检验
```
参数越多 → 越容易过拟合
规则：参数数量 ≤ log(样本量)
```

### 7.2 收益衰减检验
```
最近 N 笔交易的平均收益 << 之前 N 笔交易的平均收益
  → 策略衰减（可能过拟合或市场结构变化）
```

### 7.3 白噪声检验（Ljung-Box）
```
策略收益序列是否为白噪声？
如果是 → 策略无效（收益来自运气）
```

### Python 实现
```python
# overfiting_detection.py
from statsmodels.stats.diagnostic import acorr_ljungbox

def detect_overfiting(daily_returns):
    """
    过拟合检测
    """
    returns = np.array(daily_returns)
    
    # 1. 收益衰减检验
    n = len(returns) // 2
    recent_avg = returns[-n:].mean()
    past_avg = returns[:n].mean()
    decay = (past_avg - recent_avg) / past_avg
    
    # 2. 白噪声检验
    lb_test = acorr_ljungbox(returns, lags=[10], return_df=True)
    p_value = lb_test['lb_pvalue'].iloc[0]
    is_white_noise = p_value > 0.05  # p > 0.05 → 白噪声
    
    return {
        'return_decay': decay,
        'is_white_noise': is_white_noise,
        'overfitted': is_white_noise or decay > 0.5,
    }
```

## 8. 代码模板：完整评估框架

### 模板：策略评估报告生成器
```python
# strategy_evaluation.py
import json
from datetime import datetime

class StrategyEvaluator:
    def __init__(self, strategy_func, data, initial_capital=10000):
        self.strategy_func = strategy_func
        self.data = data
        self.initial_capital = initial_capital
    
    def run_evaluation(self, params):
        """
        完整评估流水线
        """
        # 1. 回测
        equity_curve, trade_pnls = self.strategy_func(self.data, params, self.initial_capital)
        
        # 2. 收益指标
        returns = calculate_returns(equity_curve)
        
        # 3. 风险指标
        risk = calculate_risk_metrics(equity_curve)
        
        # 4. 风险调整收益
        risk_adj = calculate_risk_adjusted(equity_curve)
        
        # 5. 交易行为
        behavior = calculate_trading_behavior(trade_pnls)
        
        # 6. 蒙特卡洛测试
        mc = monte_carlo_test(trade_pnls, n_simulations=1000)
        
        # 7. 样本外测试
        oos = oos_test(self.strategy_func, self.data)
        
        # 汇总报告
        report = {
            'strategy': self.strategy_func.__name__,
            'params': params,
            'returns': returns,
            'risk': risk,
            'risk_adjusted': risk_adj,
            'behavior': behavior,
            'monte_carlo': mc,
            'oos_test': oos,
            'passed': self._pass_criteria(risk_adj, risk, mc, oos),
        }
        
        return report
    
    def _pass_criteria(self, risk_adj, risk, mc, oos):
        """
        通过标准（可自定义）
        """
        checks = []
        
        # 1. 夏普 > 1.0
        checks.append(risk_adj['sharpe'] > 1.0)
        
        # 2. 最大回撤 < 20%
        checks.append(risk['max_drawdown'] < 0.2)
        
        # 3. 蒙特卡洛显著（p < 0.05）
        checks.append(mc['significant'])
        
        # 4. 样本外退化 < 20%
        checks.append(oos['robust'])
        
        return all(checks)
    
    def generate_report(self, report, output_file='strategy_report.json'):
        """
        生成评估报告（JSON）
        """
        # 添加时间戳
        report['timestamp'] = datetime.now().isoformat()
        
        # 保存
        with open(output_file, 'w') as f:
            json.dump(report, f, indent=2, default=str)
        
        # 打印摘要
        print("="*60)
        print(f"策略评估报告: {report['strategy']}")
        print("="*60)
        print(f"  夏普比率: {report['risk_adjusted']['sharpe']:.2f}")
        print(f"  索提诺比率: {report['risk_adjusted']['sortino']:.2f}")
        print(f"  卡玛比率: {report['risk_adjusted']['calmar']:.2f}")
        print(f"  最大回撤: {report['risk']['max_drawdown']*100:.2f}%")
        print(f"  胜率: {report['behavior']['win_rate']*100:.1f}%")
        print(f"  盈亏比: {report['behavior']['profit_factor']:.2f}")
        print(f"  蒙特卡洛 p-value: {report['monte_carlo']['p_value']:.3f}")
        print(f"  样本外退化: {report['oos_test']['degradation']*100:.1f}%")
        print(f"  通过所有检验: {'✅' if report['passed'] else '❌'}")
        print("="*60)
        
        return report
```

## 9. 评估流水线

### 推荐流程
```
1. 样本内优化（70% 数据）
   → 得到最优参数组合
  
2. 样本外测试（30% 数据）
   → 检验参数稳健性
  
3. 蒙特卡洛模拟（1000 次）
   → 检验策略是否靠运气
  
4. Walk-Forward 分析
   → 检验参数在不同时间段的稳定性
  
5. 敏感性分析
   → 检验参数微小变化对结果的影响
  
6. 如果通过所有检验 → 模拟盘测试（1-3 个月）
   → 如果模拟盘表现一致 → 实盘（小资金）
```

## 10. 总结与最佳实践

### 评估指标速查表
| 指标 | 阈值（建议） | 说明 |
|------|----------------|------|
| **夏普比率** | > 1.5 | 优秀 |
| **索提诺比率** | > 2.0 | 优秀（更严格） |
| **卡玛比率** | > 3.0 | 优秀 |
| **最大回撤** | < 20% | 必须 |
| **胜率** | > 50% | 理想 |
| **盈亏比** | > 1.5 | 必须 |
| **样本外退化** | < 20% | 必须 |
| **蒙特卡洛 p-value** | < 0.05 | 必须 |

### 最佳实践
1. **永远做样本外测试**：不下样本外测试的策略不上线
2. **蒙特卡洛是底线**：p > 0.05 的策略都是运气
3. **夏普 > 3 要警惕**：可能是过拟合
4. **Walk-Forward 比交叉验证更严格**：必须做
5. **模拟盘是最后一道防线**：样本外测试通过后，还要模拟盘 1-3 个月

### 策略上线检查清单
```
□ 样本内夏普 > 1.5
□ 样本外夏普 > 1.0
□ 样本外退化 < 20%
□ 蒙特卡洛 p-value < 0.05
□ 最大回撤 < 20%
□ Walk-Forward 一致性 > 60%
□ 敏感性分析：参数 +1% → 收益变化 < 10%
□ 模拟盘 1-3 个月表现一致
```
