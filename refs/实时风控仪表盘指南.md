## 一、什么是实时风控仪表盘？

**定义**：整合多维度风险指标，实时监控持仓风险，自动预警

**核心功能**（v3.4）：
1. **GARCH VaR/CVaR**：动态计算风险价值
2. **五级预警体系**：🟢/🟡/🟠/🔴/⚫
3. **压力测试**：极端行情下组合表现
4. **实时监控**：守护进程模式（daemon）
5. **JSON 报告导出**：便于程序化风控

**Alert 触发条件**：
- 风险等级从 🟢 → 🟡 → 🟠 → 🔴 → ⚫

- 持仓浮亏 > 5%

## 三、五级预警体系

| 等级 | 条件 | 操作建议 |
|------|------|----------|
| 🟢 GREEN | VaR(95%) < 2% | 正常开仓，仓位 ≤ 30% |
| 🟡 YELLOW | VaR(95%) 2%~5% | 警戒，仓位 ≤ 20% |
| 🟠 ORANGE | VaR(95%) 5%~10% | 减仓，仓位 ≤ 10% |
| 🔴 RED | VaR(95%) > 10% | 清仓，只留对冲仓位 |
| ⚫ BLACK | VaR(99%) > 20% | 紧急，全部平仓 |

### 3.1 自动触发规则

```python
# 在 risk_dashboard.py 中实现
def check_risk_level(var_95, var_99):
    if var_99 > 0.20:
        return "BLACK", "紧急，全部平仓"
    elif var_95 > 0.10:
        return "RED", "清仓，只留对冲仓位"
    elif var_95 > 0.05:
        return "ORANGE", "减仓，仓位 ≤ 10%"
    elif var_95 > 0.02:
        return "YELLOW", "警戒，仓位 ≤ 20%"
    else:
        return "GREEN", "正常开仓，仓位 ≤ 30%"
```

## 四、压力测试

### 4.1 测试场景

| 场景 | 参数调整 | 用途 |
|------|---------|------|
| 波动率暴涨 | σ × 2 | 测试恐慌行情 |
| 相关性→1 | ρ = 1.0 | 测试黑天鹅（所有资产同跌） |
| 流动性枯竭 | 滑点 × 5 | 测试小市值币暴跌 |
| 交易所瘫痪 | 无法平仓 | 测试极端情况 |

### 4.2 使用 `risk_dashboard.py` 进行压力测试

```bash
python scripts/risk_dashboard.py --symbols BTC,ETH,SOL --portfolio --stress-test
```

**输出示例**：
```
=== 压力测试 ===
组合：BTC(50%) + ETH(30%) + SOL(20%)

【场景1：波动率暴涨 2 倍】
VaR (99%)：$3,012 → $5,824（+93%）
建议：减仓至 10% 以下

【场景2：相关性→1.0】
VaR (99%)：$3,012 → $4,217（+40%）
建议：加入负相关资产对冲

【场景3：流动性枯竭（滑点×5）】
实际损失：VaR × 1.5 = $4,518
建议：避免小市值币重仓

【场景4：交易所瘫痪（无法平仓）】
最大损失：100%（归零）
建议：分散交易所，预留提币时间
```

## 六、Python API 调用

### 6.1 基础用法

```python
from risk_dashboard import RiskDashboard

# 初始化
dashboard = RiskDashboard(symbol='BTCUSDT', position=10000)

# 更新市场价格
dashboard.update_price(63200)

# 获取风险指标
risk_metrics = dashboard.get_risk_metrics()
print(f"VaR (95%)：{risk_metrics['var_95']:.2%}")
print(f"CVaR (95%)：{risk_metrics['cvar_95']:.2%}")

# 获取风险等级
risk_level = dashboard.get_risk_level()
print(f"风险等级：{risk_level}")

# 获取操作建议
advice = dashboard.get_advice()
print(f"建议仓位：{advice['suggested_position']:.0%}")
```

### 6.2 组合监控

```python
# 初始化组合
portfolio = {
    'BTC': 25000,
    'ETH': 15000,
    'SOL': 10000
}
dashboard = RiskDashboard(portfolio=portfolio)

# 获取组合 VaR
portfolio_var = dashboard.get_portfolio_var(confidence=0.99)
print(f"组合 VaR (99%)：-${portfolio_var:.0f}")

# 获取动态相关性
corr_matrix = dashboard.get_dynamic_correlation()
print("动态相关性矩阵：")
print(corr_matrix)

# 压力测试
stress_result = dashboard.run_stress_test(scenario='vol_double')
print(f"压力测试（波动率翻倍）：VaR = ${stress_result['var_99']:.0f}")
```

### 6.3 实时监控（守护进程）

```python
import time

dashboard = RiskDashboard(symbol='BTCUSDT', position=10000)

def on_risk_level_change(old_level, new_level):
    print(f"风险等级变化：{old_level} → {new_level}")
    if new_level == 'RED':
        print("建议：立即减仓！")

dashboard.set_risk_level_callback(on_risk_level_change)

# 开始监控（每 60 秒刷新）
dashboard.start_monitoring(interval=60, duration=1800)  # 监控 30 分钟
```

## 七、最佳实践

1. **监控频率**：
   - 日线策略：每日开盘前检查
   - 4 小时线策略：每 4 小时检查
   - 1 小时线策略：每小时检查

2. **预警阈值**：
   - 保守：YELLOW 等级就减仓
   - 标准：ORANGE 等级才减仓
   - 激进：RED 等级才减仓

3. **压力测试频率**：
   - 每月一次完整压力测试
   - 极端行情后（如 Luna/FTX）立即测试

4. **组合相关性监控**：
   - 相关性 > 0.8 → 考虑加入负相关资产
   - 相关性→1.0（极端行情）→ 立即减仓

5. **JSON 报告集成**：
   - 导出 JSON → 程序化风控（自动平仓）
   - 与交易所 API 集成 → 自动执行
