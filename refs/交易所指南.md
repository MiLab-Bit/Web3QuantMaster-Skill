## 二、API 接入方案

### 方案A：CCXT（推荐）—— 多交易所统一接口

CCXT 是加密货币最流行的统一 API 库，支持 100+ 交易所，一行代码切换交易所。

```python
import ccxt

# 初始化任意交易所
exchange = ccxt.binance()

# 获取K线
ohlcv = exchange.fetch_ohlcv('BTC/USDT', '1h', limit=100)
# 返回: [timestamp, open, high, low, close, volume]

# 获取实时行情
ticker = exchange.fetch_ticker('BTC/USDT')
# {'symbol': 'BTC/USDT', 'last': 67000.0, 'bid': 66999.0, 'ask': 67001.0,
#  'high': 68000.0, 'low': 66000.0, 'volume': 12345.67}

# 获取余额（需要 API Key）
balance = exchange.fetch_balance()

# 切换交易所（只需改这一行）
exchange = ccxt.okx()        # OKX
exchange = ccxt.bybit()      # Bybit
exchange = ccxt.gateio()     # Gate
exchange = ccxt.hyperliquid() # Hyperliquid
```

**初始化配置（带 API Key）：**
```python
binance = ccxt.binance({
    'apiKey': 'YOUR_KEY',
    'secret': 'YOUR_SECRET',
    'enableRateLimit': True,  # 自动限速
})

okx = ccxt.okx({
    'apiKey': 'YOUR_KEY',
    'secret': 'YOUR_SECRET',
    'password': 'YOUR_PASSWORD',  # OKX 专属
    'enableRateLimit': True,
})

bybit = ccxt.bybit({
    'apiKey': 'YOUR_KEY',
    'secret': 'YOUR_SECRET',
    'enableRateLimit': True,
})

gate = ccxt.gateio({
    'apiKey': 'YOUR_KEY',
    'secret': 'YOUR_SECRET',
})
```

**速率限制：**
| 交易所 | 限速 | 建议请求间隔 |
|--------|------|-----------|
| Binance | 1200次/分 | ≥ 50ms |
| OKX | 600次/分 | ≥ 100ms |
| Bybit | 600次/分 | ≥ 100ms |
| Gate | 900次/分 | ≥ 70ms |
| Hyperliquid | 高 | ≥ 10ms |

### 方案B：urllib（轻量备用）—— 无额外依赖

适合快速原型、单交易所、不想装 CCXT 的场景。

#### Binance
```python
import urllib.request, json

# K线
url = 'https://api.binance.com/api/v3/klines?symbol=BTCUSDT&interval=1h&limit=100'
req = urllib.request.Request(url, headers={'User-Agent': 'Mozilla/5.0'})
with urllib.request.urlopen(req, timeout=8) as r:
    data = json.loads(r.read())
    print('BTC收盘价:', data[-1][4])  # 第5列 = close

# 实时行情
url2 = 'https://api.binance.com/api/v3/ticker/24hr?symbol=BTCUSDT'
```

#### OKX
```python
# K线
url = 'https://www.okx.com/api/v5/market/candles?instId=BTC-USDT&bar=1h&limit=100'
# 返回格式: [ts, open, high, low, close, volume, ...]
```

#### Bybit
```python
# K线（USDT永续）
url = 'https://api.bybit.com/v5/market/kline?category=linear&symbol=BTCUSDT&interval=60&limit=100'
# category: spot | linear（永续）| inverse（币本位）
```

#### Gate
```python
# K线
url = 'https://api.gateio.biz/api/v4/spot/candlesticks?currency_pair=BTC_USDT&interval=1h&limit=100'
```

#### Hyperliquid
```python
# K线（无需认证，超低延迟）
url = 'https://api.hyperliquid.xyz/info'
payload = {"type": "candle_snapshot", "req": {"coin": "BTC", "interval": "1h", "startTime": None}}
import urllib.request, json
req = urllib.request.Request(url,
    data=json.dumps(payload).encode(),
    headers={'Content-Type': 'application/json'})
with urllib.request.urlopen(req, timeout=5) as r:
    data = json.loads(r.read())
```

## 三、注意事项

> 📖 **外部数据源 API 配置**（Alpha Vantage / Etherscan / Glassnode / Dune / Twitter 等 Token 获取方式）请参见 → [`数据源API配置指南.md`](./数据源API配置指南.md)

1. **API Key 安全**：生产环境使用环境变量存储，不要硬编码
2. **速率限制**：CCXT 的 `enableRateLimit=True` 可自动处理限速
3. **永续合约 vs 现货**：交易对格式不同
   - 现货：`BTC/USDT`（CCXT）或 `BTCUSDT`（Binance REST）
   - 永续：`BTC/USDT:USDT`（CCXT）或 `BTCUSDT`（Binance REST，fapi）
4. **数据格式**：CCXT 统一返回标准化格式，各交易所原始数据格式不同
5. **错误处理**：
```python
try:
    ticker = exchange.fetch_ticker('BTC/USDT')
except ccxt.RateLimitExceeded:
    time.sleep(60)
except ccxt.NetworkError:
    time.sleep(10)
```
