## 一、市场状态检测（最关键）

### 震荡市识别标准

**量化判断（必须同时满足 ≥3 个条件）：**

| 指标 | 震荡条件 | 检测方法 |
|------|---------|---------|
| **布林带宽度** | 带宽 < 5% | (上轨-下轨)/中轨 × 100 < 5 |
| **ATR** | ATR处于20日低位 | ATR < 20日MA(ATR) × 0.8 |
| **均线间距** | MA5与MA20价差 < 3% | abs(MA5-MA20)/MA20 < 0.03 |
| **RSI** | RSI 在 40~60 区间 | 40 < RSI < 60 持续5天 |
| **成交量** | 成交量萎缩 | VOL < 20日均量 × 0.7 |

**Python实现（震荡检测）：**
```python
def detect_sideways(df, lookback=20):
    """
    返回：'sideways'（震荡）/'trending'（趋势）/'unknown'
    """
    # 1. 布林带宽度
    ma20 = df['close'].rolling(20).mean()
    std20 = df['close'].rolling(20).std()
    bandwidth = ((ma20 + 2*std20) - (ma20 - 2*std20)) / ma20 * 100
    
    # 2. ATR相对位置
    high, low, close = df['high'], df['low'], df['close']
    tr1 = high - low
    tr2 = (high - close.shift()).abs()
    tr3 = (low - close.shift()).abs()
    tr = pd.concat([tr1, tr2, tr3], axis=1).max(axis=1)
    atr = tr.rolling(14).mean()
    atr_pos = atr.iloc[-1] / atr.rolling(20).mean().iloc[-1]
    
    # 3. 均线间距
    ma5 = df['close'].rolling(5).mean()
    ma20 = df['close'].rolling(20).mean()
    ma_gap = abs(ma5 - ma20) / ma20 * 100
    
    # 4. RSI位置
    delta = df['close'].diff()
    gain = delta.where(delta > 0, 0).rolling(14).mean()
    loss = (-delta.where(delta < 0, 0)).rolling(14).mean()
    rs = gain / loss
    rsi = 100 - (100 / (1 + rs))
    rsi_mid = (rsi.iloc[-5:] > 40) & (rsi.iloc[-5:] < 60)
    
    # 5. 成交量萎缩
    vol_ratio = df['volume'].iloc[-1] / df['volume'].rolling(20).mean().iloc[-1]
    
    # 评分（震荡条件满足数量）
    score = 0
    if bandwidth.iloc[-1] < 5: score += 1
    if atr_pos < 0.8: score += 1
    if ma_gap.iloc[-1] < 3: score += 1
    if rsi_mid.all(): score += 1
    if vol_ratio < 0.7: score += 1
    
    if score >= 3:
        return 'sideways'
    elif score <= 1:
        return 'trending'
    else:
        return 'unknown'
```

### 趋势市识别标准

**量化判断（满足任意 1 个即确认趋势）：**

| 指标 | 趋势条件 | 检测方法 |
|------|---------|---------|
| **均线多头/空头** | MA5>MA20>MA60 持续5天 | MA5 > MA20 > MA60 |
| **ATR放大** | ATR > 20日MA(ATR) × 1.3 | ATR位置 > 1.3 |
| **RSI极端值** | RSI 持续 > 60 或 < 40 | RSI > 60 或 RSI < 40 持续5天 |

| **带宽放大** | 布林带宽 > 10% | bandwidth > 10 |

## 二、震荡市核心策略

### 策略1：布林带均值回归（最经典）

**适用场景：** 带宽 < 5%，RSI 在 40~60

**参数：**
```python
period = 20       # 布林带周期
std_dev = 2       # 标准差倍数
rsi_period = 14   # RSI周期
rsi_buy = 35      # 买入RSI阈值（不过度超卖）
rsi_sell = 65     # 卖出RSI阈值（不过度超买）
```

**入场逻辑：**
```
买入条件（必须全部满足）：
  1. 价格触及布林下轨（close <= lower）
  2. 出现锤子线（下影线 > 实体 × 2）
  3. RSI < rsi_buy（不要求超卖）
  4. 成交量 = 近5日最低的50%（极度缩量）

卖出条件（满足任意1个）：
  1. 价格触及布林中轨 → 卖1/2
  2. 价格触及布林上轨 → 全卖
  3. 跌破布林下轨 → 止损
```

**Python实现：**
```python
def bollinger_reversion(df, position=0):
    ma20 = df['close'].rolling(20).mean()
    std20 = df['close'].rolling(20).std()
    upper = ma20 + 2 * std20
    lower = ma20 - 2 * std20
    
    # RSI
    delta = df['close'].diff()
    gain = delta.where(delta > 0, 0).rolling(14).mean()
    loss = (-delta.where(delta < 0, 0)).rolling(14).mean()
    rs = gain / loss
    rsi = 100 - (100 / (1 + rs))
    
    # K线形态
    body = abs(df['close'] - df['open'])
    lower_shadow = df[['open', 'close']].min(axis=1) - df['low']
    upper_shadow = df['high'] - df[['open', 'close']].max(axis=1)
    hammer = (lower_shadow > body * 2) & (upper_shadow < body * 0.5)
    
    vol_ma = df['volume'].rolling(5).mean()
    low_vol = df['volume'] < vol_ma * 0.5
    
    price = df['close'].iloc[-1]
    rsi_val = rsi.iloc[-1]
    
    if position == 0:
        # 买入信号
        if (price <= lower.iloc[-1] and 
            hammer.iloc[-1] and 
            rsi_val < 35 and 
            low_vol.iloc[-1]):
            return 'BUY'
    else:
        # 卖出信号
        if price >= ma20.iloc[-1]:
            return 'SELL_HALF'  # 中轨卖一半
        elif price >= upper.iloc[-1]:
            return 'SELL_ALL'   # 上轨全卖
        elif price < lower.iloc[-1]:
            return 'STOP_LOSS'  # 止损
    return 'HOLD'
```

### 策略2：RSI 极端值回归

**适用场景：** RSI 连续在 40~60，但偶尔触及 30 或 70

**入场逻辑：**
```
买入（RSI 超卖后反弹）：
  1. RSI(14) < 30（连续不超过2根）
  2. RSI 出现底部抬高（比前低点高）
  3. 收盘价未创新低
  → 买入，止损 = RSI 最低点 - 5%

卖出（RSI 超买后回落）：
  1. RSI(14) > 70（连续不超过2根）
  2. RSI 出现顶部降低（比前高点低）
  3. 收盘价未创新高
  → 卖出
```

**优化方案（避免假信号）：**
```
+ 只在 RSI 从 <25 的超卖区反弹时买入
+ RSI 回归到 50 附近即卖一半
+ RSI 达到 60 即全卖（不过度贪婪）
+ 连续3根 RSI 低于 30 → 不买（趋势可能向下）
```

### 策略3：网格交易（机械稳定）

**适用场景：** 价格在明确区间内震荡，无明显方向

**参数设置：**
```python
upper_price = 70000   # 区间上界
lower_price = 60000   # 区间下界
grid_count = 10       # 网格数量
grid_spacing = (upper_price - lower_price) / grid_count  # 每格间距
take_profit_pct = 1.5 # 每格止盈%
total_stop_pct = 10   # 总止损%
```

**操作逻辑：**
```
价格每下跌一格 → 买入1格
价格每上涨一格 → 卖出1格（止盈）

示例（$60K~$70K，10格）：
  $60,000 → 买入1格（$1,000）
  $61,000 → 卖出1格（赚$1,000，+1.5%）
  $62,000 → 卖出1格（赚$1,000，+1.5%）
  ...继续高抛低吸

跌穿 $60,000（区间下破）：
  → 止损全部（总亏损 -10%）
  → 停止网格，等待新区间
```

**风险管理：**
```
1. 预留 50% 资金（应对单边下跌）
2. 每格仓位 = 总资金 × 5% / 网格数
3. 区间设置：参考最近 60 天的最高/最低价
4. 带宽 > 10% 时不开启网格（趋势市场）
```

## 三、震荡市 vs 趋势市策略切换

### 切换决策树

```
当前市场状态检测：
  │
  ├── 震荡市（score ≥ 3）：
  │     ├── 布林带均值回归（优先）
  │     ├── RSI 极端值
  │     ├── 网格交易
  │     └── 箱体突破
  │
  ├── 趋势市（score ≤ 1）：
  │     ├── 均线交叉（MA5/MA20）
  │     ├── MACD 金叉死叉
  │     ├── 突破策略（顺势）
  │     └── 移动止损（追踪利润）
  │
  └── 未知（score = 2）：
        ├── 观望，不开新仓
        └── 轻仓尝试方向
```

### 动态切换逻辑

```python
def get_strategy_for_regime(regime, position=0):
    if regime == 'sideways':
        return {
            'primary': 'bollinger_reversion',
            'secondary': ['rsi_extreme', 'grid'],
            'stop_loss': 'bollinger_lower',  # 止损在布林下轨
            'position_size': 0.8,  # 震荡市轻仓
            'trend_filter': True   # 仍需趋势过滤
        }
    elif regime == 'trending':
        return {
            'primary': 'ma_crossover',
            'secondary': ['macd_cross', 'breakout'],
            'stop_loss': 'atr_based',  # ATR止损
            'position_size': 1.0,  # 趋势市重仓
            'trend_filter': False
        }
    else:
        return {
            'primary': 'wait',
            'secondary': [],
            'stop_loss': None,
            'position_size': 0.3,  # 未知市，轻仓
            'trend_filter': True
        }
```

## 四、震荡市常见陷阱

| 陷阱 | 表现 | 量化识别 | 应对 |
|------|------|---------|------|
| **假突破** | 突破后3天内回落 | 突破时成交量 < 均量1.5倍 | 等回踩确认再买 |
| **趋势陷阱** | 均线看似金叉，实为震荡 | RSI 在 40~60 区间 | RSI不在极端区不用MA信号 |
| **连续亏损** | RSI策略连续失败 | RSI < 30 连续超过5根 | 切换到网格或观望 |
| **方向判断错** | 以为是震荡，实为趋势 | ATR持续放大 | 布林带宽 > 8% = 趋势确认 |
| **不止损** | 震荡市不止损套牢 | 价格跌破下轨3天不回来 | 下轨跌破即止损 |
