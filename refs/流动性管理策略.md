## 一、Uniswap V3 流动性头寸管理

### 核心概念

Uniswap V3 允许 LP 在特定价格区间内提供流动性，实现「集中流动性」：

```
传统 AMM: 流动性均匀分布在 [0, +∞)
Uniswap V3: 流动性集中在 [P_min, P_max]
```

**流动性深度计算**：
```python
def calc_uniswap_v3_depth(
    token0_amount: float,  # USDC 数量
    token1_amount: float,  # ETH 数量
    current_price: float,  # 当前 ETH/USDC 价格
    price_min: float,      # 区间最低价
    price_max: float       # 区间最高价
) -> dict:
    """
    计算 Uniswap V3 流动性头寸的有效深度
    """
    # 计算虚拟流动性（k = sqrt(x * y)）
    k_virtual = token0_amount * token1_amount / (token0_amount / token1_amount + 1) ** 0.5
    
    # 价格在区间内：使用真实资产
    if price_min <= current_price <= price_max:
        in_range_ratio = 1.0
        virtual_liquidity = k_virtual
    else:
        # 价格在区间外：完全转换为单边资产（无偿损失）
        in_range_ratio = 0.0
        virtual_liquidity = 0
    
    # 等效 USD 深度
    depth_usd = min(token0_amount, token1_amount * current_price) * 2
    
    return {
        "in_range": price_min <= current_price <= price_max,
        "in_range_ratio": in_range_ratio,
        "depth_usd": depth_usd,
        "virtual_liquidity": virtual_liquidity,
        "impermanent_loss": calc_impermanent_loss(current_price, price_min, price_max)
    }

def calc_impermanent_loss(price_current, price_min, price_max):
    """计算无常损失（IL）"""
    # IL = 2 * sqrt(rate) / (1 + rate) - 1
    # 其中 rate = P_current / P_initial
    if price_current <= price_min:
        rate = price_min / price_current
        il = 2 * (rate ** 0.5) / (1 + rate) - 1
    elif price_current >= price_max:
        rate = price_max / price_current
        il = 2 * (rate ** 0.5) / (1 + rate) - 1
    else:
        il = 0
    return abs(il) * 100  # 转为百分比
```

### 流动性头寸策略

**策略1：紧密区间 + 高收益（高风险）**
```
适用场景：波动率低、价格区间明确
操作：
  - 设置 5% 区间（如 ETH $3000-3150）
  - 预期手续费收益：日化 0.1-0.5%
风险：
  - 价格突破区间 → 100% IL
  - 需持续调整区间
```

**策略2：宽松区间 + 低风险**
```
适用场景：高波动、方向不明
操作：
  - 设置 30-50% 区间（如 ETH $2400-3600）
  - 预期手续费收益：日化 0.02-0.1%
优势：
  - 减少调仓频率
  - 降低 IL 风险
```

## 二、AMM 流动性分布分析

### 流动性「墙」检测

流动性集中的价格区域形成「墙」，价格触及这些区域时会快速反弹或突破：

```python
from web3 import Web3
import json

def detect_liquidity_walls(pool_address: str, web3: Web3, min_depth_usd=10000):
    """
    检测 Uniswap V3 池子的流动性「墙」
    
    流动性「墙」：某价格区间内流动性异常集中的区域
    价格触及流动性「墙」时，通常会发生：
      - 支撑位：快速反弹
      - 阻力位：快速回落
    """
    # 获取池子的流动性事件
    # 实际需要解析 TickLiquidty 事件
    
    liquidity_depth = {}  # {price: depth}
    
    # 模拟：假设从 subgraph 或 RPC 获取流动性数据
    # 这里用简化模型
    for tick in range(-1000, 1000):
        price = 3000 * (1.0001 ** tick)
        liquidity = fetch_tick_liquidity(pool_address, tick)
        if liquidity > min_depth_usd / 3000:
            liquidity_depth[price] = liquidity
    
    # 找出主要流动性「墙」
    walls = []
    prices = sorted(liquidity_depth.keys())
    
    for i, price in enumerate(prices):
        depth = liquidity_depth[price]
        # 找出局部深度峰值
        prev_depth = liquidity_depth.get(prices[i-1], 0) if i > 0 else 0
        next_depth = liquidity_depth.get(prices[i+1], 0) if i < len(prices)-1 else 0
        
        if depth > prev_depth and depth > next_depth and depth > min_depth_usd:
            walls.append({
                "price": price,
                "depth_usd": depth * price,
                "type": "wall"
            })
    
    return sorted(walls, key=lambda x: x["depth_usd"], reverse=True)

def fetch_tick_liquidity(pool_address, tick):
    """从池子获取指定 tick 的流动性"""
    # 实际实现：从事件日志或 subgraph 获取
    # 这里返回模拟数据
    import random
    base = 1000000  # 基础流动性
    volatility = abs(tick % 100) * 10000  # 波动性影响
    return base + random.uniform(0, volatility)
```

## 三、订单簿流动性扫描

### CEX 订单簿分析

```python
import requests
import numpy as np

def analyze_orderbook_depth(symbol="BTCUSDT", exchange="binance", levels=20):
    """
    分析交易所订单簿深度
    返回流动性分布图和关键价格点
    """
    # 获取订单簿数据
    if exchange == "binance":
        url = f"https://api.binance.com/api/v3/depth?symbol={symbol}&limit={levels}"
    elif exchange == "okx":
        url = f"https://www.okx.com/api/v5/market/books?instId={symbol.replace('USDT', '-USDT')}&sz={levels}"
    
    resp = requests.get(url).json()
    
    # 解析订单簿
    if exchange == "binance":
        bids = [[float(p), float(q)] for p, q in resp.get("bids", [])]
        asks = [[float(p), float(q)] for p, q in resp.get("asks", [])]
    elif exchange == "okx":
        bids = [[float(b[0]), float(b[1])] for b in resp.get("data", [{}])[0].get("bids", [])]
        asks = [[float(a[0]), float(a[1])] for a in resp.get("data", [{}])[0].get("asks", [])]
    
    # 计算累计深度
    bid_cum = np.cumsum([q for _, q in bids])
    ask_cum = np.cumsum([q for _, q in asks])
    
    mid_price = (bids[0][0] + asks[0][0]) / 2
    
    # 检测流动性「墙」
    # 「墙」= 某价格区间内累计成交量异常高
    wall_threshold = max(bid_cum.max(), ask_cum.max()) * 0.1  # 10% 阈值
    
    bid_walls = []
    for i, (price, qty) in enumerate(bids):
        if i > 0 and qty > bids[i-1][1] * 2:  # 当前档位量是上一档的2倍以上
            bid_walls.append({"price": price, "qty": qty, "type": "bid_wall"})
    
    ask_walls = []
    for i, (price, qty) in enumerate(asks):
        if i > 0 and qty > asks[i-1][1] * 2:
            ask_walls.append({"price": price, "qty": qty, "type": "ask_wall"})
    
    return {
        "mid_price": mid_price,
        "bid_walls": bid_walls[:3],
        "ask_walls": ask_walls[:3],
        "total_bid_depth": sum(q for _, q in bids),
        "total_ask_depth": sum(q for _, q in asks),
        "bid_ask_ratio": sum(q for _, q in bids) / max(sum(q for _, q in asks), 1),
        "spread": asks[0][0] - bids[0][0] if asks and bids else 0,
        "spread_pct": (asks[0][0] - bids[0][0]) / mid_price * 100 if asks and bids else 0
    }

def trading_signal_from_orderbook(depth_analysis):
    """
    基于订单簿深度生成交易信号
    """
    signals = []
    
    # 信号1：Bid Walls（买墙）→ 潜在支撑
    if depth_analysis["bid_walls"]:
        wall = depth_analysis["bid_walls"][0]
        distance_pct = (depth_analysis["mid_price"] - wall["price"]) / depth_analysis["mid_price"] * 100
        if distance_pct < 0.5:  # 距离小于0.5%
            signals.append({
                "type": "BID_WALL",
                "direction": "bullish",
                "confidence": 0.7,
                "message": f"买墙在 ${wall['price']:.2f}，距现价 {distance_pct:.2f}%，潜在支撑"
            })
    
    # 信号2：Ask Walls（卖墙）→ 潜在阻力
    if depth_analysis["ask_walls"]:
        wall = depth_analysis["ask_walls"][0]
        distance_pct = (wall["price"] - depth_analysis["mid_price"]) / depth_analysis["mid_price"] * 100
        if distance_pct < 0.5:
            signals.append({
                "type": "ASK_WALL",
                "direction": "bearish",
                "confidence": 0.7,
                "message": f"卖墙在 ${wall['price']:.2f}，距现价 {distance_pct:.2f}%，潜在阻力"
            })
    
    # 信号3：买卖深度失衡
    if depth_analysis["bid_ask_ratio"] > 2:
        signals.append({
            "type": "DEPTH_IMBALANCE",
            "direction": "bullish",
            "confidence": 0.6,
            "message": f"买方深度是卖方 {depth_analysis['bid_ask_ratio']:.1f} 倍，看涨"
        })
    elif depth_analysis["bid_ask_ratio"] < 0.5:
        signals.append({
            "type": "DEPTH_IMBALANCE",
            "direction": "bearish",
            "confidence": 0.6,
            "message": f"卖方深度是买方 {1/depth_analysis['bid_ask_ratio']:.1f} 倍，看跌"
        })
    
    return signals
```

## 四、跨DEX流动性套利

### 价差检测策略

```python
import asyncio
import aiohttp

# DEX 价格源
DEX_ENDPOINTS = {
    "uniswap_v2": "https://api.thegraph.com/subgraphs/name/uniswap/uniswap-v2",
    "uniswap_v3": "https://api.thegraph.com/subgraphs/name/uniswap/uniswap-v3",
    "sushiswap": "https://api.thegraph.com/subgraphs/name/sushiswap/exchange",
    "curve": "https://api.curve.fi/v1/get pools/1",
}

async def get_dex_price(session, dex_name, token_pair, pool_address):
    """获取指定 DEX 的交易对价格"""
    # 简化实现：实际需要从 The Graph 或 DEX 合约获取
    async with session.get(f"https://api.dexscreener.com/latest/dex/pairs/ethereum/{pool_address}") as resp:
        data = await resp.json()
        if data.get("pairs"):
            return {
                "dex": dex_name,
                "price": float(data["pairs"][0]["priceUsd"]),
                "liquidity": float(data["pairs"][0].get("liquidity", {}).get("usd", 0))
            }
    return None

async def scan_cross_dex_arbitrage(token_pair="WETH", stablecoin="USDC", pools=None):
    """
    扫描跨 DEX 流动性套利机会
    
    套利条件：
      1. 价差 > Gas 成本 + 滑点 + 手续费
      2. 流动性充足（单笔交易额 < 流动性的 1%）
    
    套利收益估算：
      利润 = |P_dex1 - P_dex2| * 交易量 - Gas - 手续费 - 滑点
    """
    if pools is None:
        pools = {
            "uniswap_v3": "0x...",  # 实际池子地址
            "sushiswap": "0x...",
            "curve": "0x..."
        }
    
    async with aiohttp.ClientSession() as session:
        tasks = [
            get_dex_price(session, dex, token_pair, pool)
            for dex, pool in pools.items()
        ]
        prices = await asyncio.gather(*tasks)
    
    prices = [p for p in prices if p is not None]
    if len(prices) < 2:
        return {"opportunity": False, "message": "数据不足"}
    
    # 按价格排序
    prices.sort(key=lambda x: x["price"])
    
    # 计算最大套利机会
    best_buy = prices[0]   # 最低价
    best_sell = prices[-1] # 最高价
    
    price_diff = best_sell["price"] - best_buy["price"]
    price_diff_pct = price_diff / best_buy["price"] * 100
    
    # 估算成本
    gas_cost_usd = 15  # ETH 主网约 $15-50
    fee_pct = 0.3      # Uniswap V2 0.3%
    slippage_pct = 0.1 # 预估滑点
    total_cost_pct = gas_cost_usd / 10000 + fee_pct + slippage_pct  # 假设交易 $10,000
    
    # 净收益
    net_profit_pct = price_diff_pct - total_cost_pct
    
    return {
        "opportunity": net_profit_pct > 0,
        "buy_dex": best_buy["dex"],
        "buy_price": best_buy["price"],
        "sell_dex": best_sell["dex"],
        "sell_price": best_sell["price"],
        "price_diff_pct": price_diff_pct,
        "net_profit_pct": net_profit_pct,
        "action": f"在 {best_buy['dex']} 买入，在 {best_sell['dex']} 卖出"
    }

def estimate_arbitrage_profit(
    price_buy: float,
    price_sell: float,
    trade_amount_usd: float,
    gas_cost_usd: float = 20,
    fee_pct: float = 0.3,
    slippage_pct: float = 0.1
):
    """
    估算套利利润
    
    Args:
        price_buy: 买入价格
        price_sell: 卖出价格
        trade_amount_usd: 交易金额（USD）
        gas_cost_usd: Gas 成本（USD）
        fee_pct: 交易手续费（%）
        slippage_pct: 预估滑点（%）
    """
    tokens_bought = trade_amount_usd / price_buy
    tokens_sold = tokens_bought * (1 - fee_pct/100)
    
    gross_proceeds = tokens_sold * price_sell
    gross_profit = gross_proceeds - trade_amount_usd
    
    net_profit = gross_profit - gas_cost_usd
    net_profit_pct = net_profit / trade_amount_usd * 100
    
    return {
        "tokens_bought": tokens_bought,
        "gross_profit_usd": gross_profit,
        "net_profit_usd": net_profit,
        "net_profit_pct": net_profit_pct,
        "profitable": net_profit > 0
    }
```

## 五、流动性枯竭预警

### 流动性危机指标

```python
def liquidity_crisis_indicators(symbol="BTCUSDT"):
    """
    计算流动性危机预警指标
    用于判断市场流动性是否即将枯竭
    """
    import requests
    
    # 获取 Binance 订单簿
    url = "https://api.binance.com/api/v3/depth?symbol=BTCUSDT&limit=100"
    data = requests.get(url).json()
    
    bids = [[float(p), float(q)] for p, q in data.get("bids", [])]
    asks = [[float(p), float(q)] for p, q in data.get("asks", [])]
    
    mid_price = (bids[0][0] + asks[0][0]) / 2
    
    # 指标1：买卖盘厚度比
    bid_depth_1pct = sum(q for p, q in bids if (mid_price - p) / mid_price < 0.01)
    ask_depth_1pct = sum(q for p, q in asks if (p - mid_price) / mid_price < 0.01)
    depth_ratio = bid_depth_1pct / max(ask_depth_1pct, 1)
    
    # 指标2：1% 深度（价格偏离 1% 内的总成交量）
    depth_1pct = bid_depth_1pct + ask_depth_1pct
    depth_1pct_usd = depth_1pct * mid_price
    
    # 指标3：买卖盘价差（Spread）
    spread = asks[0][0] - bids[0][0]
    spread_pct = spread / mid_price * 100
    
    # 指标4：订单簿集中度（Top 10 / Total）
    top10_bid = sum(q for _, q in bids[:10])
    total_bid = sum(q for _, q in bids)
    bid_concentration = top10_bid / max(total_bid, 1)
    
    # 预警阈值
    warnings = []
    
    if spread_pct > 0.1:  # 价差 > 0.1%
        warnings.append({
            "level": "HIGH",
            "indicator": "SPREAD",
            "value": f"{spread_pct:.3f}%",
            "message": "买卖价差异常扩大，流动性紧张"
        })
    
    if depth_ratio < 0.3 or depth_ratio > 3:  # 深度失衡
        warnings.append({
            "level": "MEDIUM",
            "indicator": "DEPTH_IMBALANCE",
            "value": f"{depth_ratio:.2f}",
            "message": "买卖盘深度失衡，可能出现单边行情"
        })
    
    if depth_1pct_usd < 1000000:  # $1M 以下为低流动性
        warnings.append({
            "level": "HIGH",
            "indicator": "LOW_LIQUIDITY",
            "value": f"${depth_1pct_usd/1e6:.2f}M",
            "message": "1% 深度不足 $1M，警惕大单冲击"
        })
    
    if bid_concentration > 0.8:  # Top 10 占 80% 以上
        warnings.append({
            "level": "MEDIUM",
            "indicator": "CONCENTRATION",
            "value": f"{bid_concentration:.1%}",
            "message": "订单簿高度集中，警惕大单消失后的流动性崩塌"
        })
    
    return {
        "symbol": symbol,
        "mid_price": mid_price,
        "depth_1pct_usd": depth_1pct_usd,
        "spread_pct": spread_pct,
        "bid_concentration": bid_concentration,
        "warnings": warnings,
        "crisis_level": "HIGH" if any(w["level"] == "HIGH" for w in warnings) else "MEDIUM" if warnings else "LOW"
    }
```

## 💡 流动性管理实战要点

1. **开仓前必查流动性**
   - 订单簿深度 < $1M 时，避免大额开仓
   - 滑点设置需根据流动性调整（低流动性 → 高滑点容忍）

2. **Uniswap V3 LP 的流动性「墙」策略**
   - 紧密区间 → 高收益但高 IL 风险
   - 宽松区间 → 低收益但低风险
   - 建议根据波动率调整区间宽度

3. **跨 DEX 套利注意事项**
   - 必须在同一区块内完成（Flashbots/MEV-Boost）
   - Gas 成本估算需包含失败交易的费用
   - 优先选择流动性好的池子（深度 > $1M）

4. **流动性枯竭预警**
   - 主流币流动性好，预警较少触发
   - 山寨币/新币流动性差，需密切关注
   - L2 项目的 ETH 跨链时尤其注意流动性
