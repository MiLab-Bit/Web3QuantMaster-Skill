## 核心宏观指标

### 1. 美国利率

| 指标 | 影响 | 币圈反应 |
|------|------|----------|
| 利率上升 | 资金收紧 | 📉 跌 |
| 利率下降 | 资金宽松 | 📈 涨 |

**重要事件**：
- FOMC会议（每年8次）
- 利率决议
- 点阵图

**币圈联动**：
```
利率 > 5% → 资金流入银行 → 币市跌
利率 < 3% → 资金流出 → 币市涨
```

---

### 2. CPI（通胀）

| 指标 | 影响 | 币圈反应 |
|------|------|----------|
| CPI上升 | 通胀预期 | 📈 涨（抗通胀） |
| CPI下降 | 通胀缓解 | 📉 跌 |

**数据发布**：每月第二个周五

**联动**：
```
BTC ≈ 数字黄金
高CPI → BTC涨
低CPI → BTC跌
```

---

### 3. 非农就业

| 指标 | 影响 | 币圈反应 |
|------|------|----------|
| 好于预期 | 经济好 | 📉 跌（美联储收紧） |
| 差于预期 | 经济差 | 📈 涨（美联储放水） |

**数据发布**：每月第一个周五

---

### 4. GDP（GDP）

| 指标 | 影响 |
|------|------|
| GDP增长 | 经济好 |
| GDP下降 | 经济差 |

**联动**：
```
GDP高 → 加息 → 币市跌
GDP低 → 降息 → 币市涨
```

## 实战要点

### 1. 关注发布时刻
```
CPI发布时：波动剧烈
建议：提前挂单，避免追涨杀跌
```

### 2. 趋势大于数据
```
长期趋势 > 单一数据
不要因为一个数据改变整体判断
```

### 3. 预期差
```
预期：涨
实际：跌
→ 反向操作
```

## 叙事轮动路径 v3.2 NEW

> Web3 特有的资金轮动规律，传统量化没有对应物

### BTC.D（BTC Dominance）轮动框架

| BTC.D 变化 | 资金流向 | 操作方向 |
|-----------|---------|----------|
| BTC.D 上升 | 资金回流 BTC | 减山寨仓，加BTC |
| BTC.D 见顶回落 | 资金开始外溢 | 准备布局L1/赛道币 |
| BTC.D 持续下降 | 山寨季 | 加仓赛道龙头 |
| BTC.D 触底反弹 | 山寨季结束 | 减山寨仓，回BTC/USDT |

### 叙事轮动顺序（典型牛市）
```
BTC → ETH → L1(SOL/AVAX) → 赛道龙头(DeFi/GameFi) → MEME → 回BTC
```

**轮动信号检测：**
1. BTC 连续3天跑赢 ETH → 资金回流 BTC，减山寨
2. ETH/BTC 汇率连涨3天 → 山寨即将启动
3. SOL 单日涨幅 > BTC × 2 → 山寨季进行中
4. MEME 市值占加密总市值 > 5% → 山寨季晚期信号

### 事件驱动模板 v3.2 NEW

以下事件发生时，使用对应模板评估影响：

**上币事件：**
```
触发：新币上线 Binance/OKX
影响：短期内相关赛道币涨跌
操作模板：
  1. 判断新币所属赛道
  2. 赛道龙头是否有跟涨机会
  3. 上线后24h不追高
  4. 等5-7天回调再考虑
```

**减半事件：**
```
触发：BTC减半（每4年）
历史规律：
  - 减半前6个月：震荡上行
  - 减半后3个月：可能回调
  - 减半后12-18个月：主升浪
操作模板：
  1. 减半前建仓BTC（分3批）
  2. 减半后3个月内不加仓
  3. 减半后1年开始减仓
```

**监管事件：**
```
触发：SEC/CFTC/各国监管公告
影响：短期恐慌（-10%~-30%），但历史上每次都是买点
操作模板：
  1. 不在恐慌时卖出
  2. 等企稳后加仓（一般48h内）
  3. 重点关注被点名的币种（风险更高）
```

**空投事件：**
```
触发：重大项目空投（如 Arbitrum, Starknet）
影响：
  - 空投前：生态TVL上升，相关币上涨
  - 空投后：抛压导致短期下跌
操作模板：
  1. 空投前2周：关注生态代币
  2. 空投日：减仓相关代币（规避抛压）
  3. 空投后1周：观察抛压是否消化
```
