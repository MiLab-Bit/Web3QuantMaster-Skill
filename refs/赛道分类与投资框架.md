## 二、BTC（比特币）

### 定位
数字黄金，宏观对冲工具，币圈基准。

### 估值框架
| 指标 | 公式 | 含义 |
|------|------|------|
| MVRV | 市值 / 已实现市值 | >3.5高估，<1.5低估 |
| SOPR | 卖出价值 / 买入价值 | >1.5高估，<1.0底部 |
| RHODL | 带权已实现cap比率 | 极度高估信号 |
| 库存流量比 | S2F | 稀缺性指标 |

### 风险评级：⭐（最低）
- 流动性：⭐⭐⭐⭐⭐
- 波动性：⭐⭐⭐（日均3~5%）
- 监管风险：⭐⭐（全球共识资产）
- 技术风险：⭐（最成熟，无智能合约）

### 投资框架
```
✅ 长期持有：每次减半后持有4年周期
✅ 定投：每周/每月固定金额
✅ 配置比例：总仓位30~60%
✅ 止损：长持可不设，短线-8%
```

## 三、ETH（以太坊）

### 定位
智能合约龙头，DeFi + NFT + L2 底层，价值互联网基础设施。

### 估值框架
| 指标 | 含义 | 参考值 |
|------|------|-------|
| PE Ratio | 市值 / 协议收入 | <50低估 |
| FDV/Revenue | 完全稀释估值/年收入 | 行业均值30~60 |
| ETH/BTC Ratio | 相对BTC表现 | 长期看0.04~0.15 |
| Gas消耗 | 网络活跃度 | 高Gas=高需求 |

### 关键指标监控
```
Etherscan Gas Tracker：gas费用 > 50 gwei → 网络极度活跃
质押收益率：年化 3~5%
L2交易占比：持续提升 → ETH需求增加
```

### 风险评级：⭐⭐（很低）
- 流动性：⭐⭐⭐⭐⭐
- 波动性：⭐⭐⭐（日均4~6%）
- 监管风险：⭐⭐
- 技术风险：⭐（升级已完成，无重大风险）

### 投资框架
```
✅ 配置比例：总仓位15~30%
✅ 持有周期：1~4年
✅ 事件驱动：L2空投前、质押率变化
✅ 关注：ETF净流入、质押量变化
```

## 五、Layer2 扩容

### 估值方法
```
关键指标：
1. TVL（锁仓量）—— 直接反映使用需求
2. 活跃用户数（AAU）—— 真实活跃度
3. Gas节省比例 —— 相比L1节省多少
4. 代币解锁时间表 —— 通胀风险

FDV合理性判断：
FDV / 年收入 < 30 → 可接受
FDV / 年收入 > 100 → 极度高估
```

### 风险评级：⭐⭐（低）
- 安全性依赖主链（L1风险）
- 代币通胀压力大（VC持仓解锁）
- 竞争激烈（Rollup路线之争）

### 投资框架
```
✅ ARB/OP：生态成熟，龙头确定
✅ MATIC：Polygon已转型，非纯粹L2
✅ 关注：主网上线、DApp迁移、TVL突破
✅ 警惕：代币解锁前的抛压（代币经济学）
✅ 配置：总仓位 5~15%
```

## 六、DeFi（去中心化金融）

### 核心估值指标

| 指标 | 公式 | 解读 |
|------|------|------|
| **TVL** | 锁仓总价值 | 协议规模，TVL增长=需求增加 |
| **协议收入** | 用户费用总和 | 直接反映商业模式 |
| **收入/FDV** | 年化协议收入/完全稀释估值 | PE比的DeFi版，<50合理 |
| **Token/ETH** | 代币相对ETH表现 | 反映代币相对价值 |

### 各细分赛道分析

**借贷协议（AAVE, Compound）**
```
收入来源：借款人利息
关键指标：借款量、存款量、利率
风险：黑客攻击（历史多次）
估值：PE < 30 合理
```

**DEX（Uniswap, Curve）**
```
收入来源：交易手续费（0.01~0.3%）
关键指标：日交易量、流动性、费率
风险：V2/V3迁移、VC抛压
估值：PE < 40 合理
```

**衍生品（Dydx, GMX）**
```
收入来源：合约手续费 + 清算费用
关键指标：OI（未平仓合约）、交易量
风险：合约漏洞、监管
估值：高弹性，高风险高收益
```

**收益聚合（Yearn, Convex）**
```
收入来源：收益再投资
关键指标：TVL、收益率
风险：智能合约风险、无常损失
```

### 风险评级：⭐⭐⭐（中高）
- 智能合约漏洞（历史损失超$10亿）
- 无常损失（LP风险）
- 监管不确定性（SEC关注）

### 投资框架
```
✅ 选龙头：TVL排名前5
✅ 看协议收入：持续盈利 > 补贴维持
✅ 审计报告：已审计 + Bug Bounty
✅ 警惕：TVL靠激励代币维持（非真实需求）
✅ 配置：总仓位 5~15%
```

### 风险评估矩阵

| 稳定币 | 抵押类型 | 储备透明度 | 风险等级 | 投资建议 |
|--------|---------|-----------|---------|---------|
| USDT | 部分抵押 | 低（曾被质疑） | ⭐⭐ | 可用，监控新闻 |
| USDC | 完全抵押 | 高（CIRCLE审计） | ⭐ | 最安全 |
| DAI | 超额抵押 | 高 | ⭐⭐ | 去中心化但复杂 |
| UST | 算法（已崩） | — | ⭐⭐⭐⭐⭐ | 禁止 |

### 风险监控指标
```
USDC溢价：
  溢价 > +0.5% → 市场恐慌买入USDC
  溢价 < -0.5% → 市场恐慌卖出USDC（UST事件后参考）

链上储备：
  查看链上资产：USDC → Ethereum主网储备证明
  黄金储备 → 白银储备过渡（DAI教训）
```

### 投资框架
```
✅ 日常使用：USDC > USDT（安全性优先）
✅ 大额存储：分散（50% USDC + 50% USDT）
✅ 永不使用：UST（已归零）
✅ 监控溢价：溢价 > 1% = 风险信号
```

## 八、Memecoin

### 估值方法
```
❌ 无基本面
✅ 纯社区/叙事价值

关注指标：
1. 推特讨论量（微博类似的热度）
2. 持有地址数（庄家 vs 散户）
3. 大户持仓集中度（鲸鱼行为）
4. 马斯克推文效应
5. 合约是否流动性锁定
```

### 风险评级：⭐⭐⭐⭐⭐（极高）
- 无内在价值
- 流动性差（买入/卖出滑点巨大）
- 庄家控盘严重
- 归零概率高（95%+ Memecoin归零）

### 投资框架
```
✅ 娱乐仓位：只投入可接受全部亏损的资金
✅ 建议配置：总仓位 1~5%
✅ 止损必须：-30%无条件止损
✅ 止盈策略：涨10倍减半，20倍走人
✅ 不追高：等回调，不FOMO
✅ 关注：合约安全性（先查是否有流动性锁）
```

## 九、赛道轮动规律

### 周期规律
```
牛初（减半后6个月内）：
  BTC → ETH → 主流DeFi → 山寨币

牛中（BTC突破前高）：
  Layer1 → Layer2 → DeFi → GameFi

牛末（大盘见顶信号）：
  Meme → 新公链 → 山寨币（最后的疯狂）

熊市（全面下跌）：
  现金为王 → BTC/ETH → 优质DeFi（生存下来）
```

### 风险收益对比
```
高风险高收益（10x+潜力）：
  Memecoin、IDO/IEO、Meme币

中高风险（3~5x潜力）：
  Layer1潜力链、DeFi新叙事

中风险（1~3x潜力）：
  Layer2龙头、ETH生态

低风险（0.5~2x潜力）：
  BTC、ETH、优质DeFi（成熟协议）
```

### 仓位配置模板

| 类别 | 保守 | 均衡 | 激进 |
|------|------|------|------|
| BTC | 40% | 30% | 20% |
| ETH | 30% | 25% | 20% |
| Layer2/公链 | 10% | 20% | 15% |
| DeFi | 10% | 15% | 15% |
| 稳定币 | 10% | 5% | 0% |
| 基础设施 | 0% | 5% | 10% |
| Memecoin | 0% | 0% | 5% |
| 合约对冲 | 0% | 0% | 15% |

### 赛道选择决策树
```
新手入门 → BTC/ETH定投
稳健增值 → + 优质Layer2（ARB/OP）
追求收益 → + DeFi流动性挖矿
高风险爱好 → + Memecoin（≤5%）
长期持有 → 现货为主，减少合约
```

### 再平衡规则
```
每季度检查一次：
- 单赛道偏差 > 15% → 再平衡
- 大盘单周跌 > 20% → 检查仓位
- 发现新赛道机会 → 卖弱补强
```
