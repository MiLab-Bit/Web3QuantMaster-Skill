# QuantMaster 快速入门指南

## 5分钟入门

### 第1步：连接数据（可选）
```
输入：连接Binance API
→ 需要配置API Key
```

### 第2步：诊断现有策略
```
输入：帮我诊断这个策略
策略：MA5上穿MA20买入，MA5下穿MA20卖出

→ Skill回复：
━━━━━━━━━━━━━━━━━━━━
📊 策略诊断报告

✅ 优势
- 逻辑简单，易于执行
- 牛市中表现优异

⚠️ 风险
- 震荡市频繁假信号
- 滞后性强，追高被套

💡 优化建议
1. 加入成交量过滤（放量突破才买入）
2. 添加RSI过滤（RSI<70才买）
3. 止损设为-5%
━━━━━━━━━━━━━━━━━━━━
```

```
输入：/risk-check
→ Skill回复：

🛡️ 持仓风险报告

## 常用命令速查

| 命令 | 功能 | 示例回复 |
|------|------|----------|
| `/strategy-check` | 策略诊断 | 诊断报告+优化建议 |
| `/factor-analyze` | 因子分析 | 相关性矩阵+组合建议 |
| `/risk-check` | 风控检测 | 风险评分+调整建议 |
| `/tech-stack` | 技术选型 | 推荐框架+数据源 |
| `/backtest` | 历史回测 | 收益率+回撤+胜率 |
| `/paper-trade` | 模拟交易 | 持仓+盈亏 |
| `/alert` | 价格提醒 | 提醒列表 |
| `/portfolio` | 组合分析 | 配置饼图+相关性 |

### 风控检测
```
用户：看看我的仓位有没有风险

→ Skill回复：
━━━━━━━━━━━━━━━━━━━━
🛡️ 风控检测

📊 当前持仓
- BTC @ $67,000 | 50% | +12%
- ETH @ $3,200 | 30% | +8%
- SOL  @ $180  | 15% | +25%

⚠️ 风险提示
- BTC占比50%，超过单币40%上限
- 无止损设置
- 全部现货，无对冲

💡 调整建议
1. 减持BTC至40%
2. 设置BTC止损$60,300(-10%)
3. 建议配置5%稳定币
━━━━━━━━━━━━━━━━━━━━


用户：止损设多少合适

→ Skill回复：
━━━━━━━━━━━━━━━━━━━━
🛡️ 止损建议

📊 币种分析
- BTC波动性：中 │ 建议止损：-8%
- ETH波动性：中 │ 建议止损：-8%
- SOL波动性：高 │ 建议止损：-12%

📐 计算依据
- ATR(14)作为参考
- 2倍ATR作为止损

⚠️ 原则
- 单笔亏损<2%
- 总仓位亏损<5%
