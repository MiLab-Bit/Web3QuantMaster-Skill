## 1. 资金费率机制原理

### 什么是资金费率？
永续合约（Perpetual Futures）没有到期日，为了锚定现货价格，引入**资金费率（Funding Rate）**机制：

```
每 8 小时结算一次（Binance/Bybit/OKX）
  多方（Long）支付给空方（Short）  ← 当 funding rate > 0
  空方（Short）支付给多方（Long）  ← 当 funding rate < 0
```

### 费率计算公式（Binance）
```
Funding Rate = (溢价指数 Premium Index) + Clamp(利率差, -0.05%, +0.05%)

溢价指数 = (永续标记价格 - 现货价格) / 现货价格
利率差 = 0.03% (默认多空利率相同)
```

### 结算时间（UTC）
| 交易所 | 结算时间（UTC） | 结算频率 |
|---------|------------------|----------|
| Binance | 00:00, 08:00, 16:00 | 每 8h |
| Bybit | 00:00, 08:00, 16:00 | 每 8h |
| OKX | 00:00, 08:00, 16:00 | 每 8h |
| Huobi | 00:00, 08:00, 16:00 | 每 8h |

## 4. 套利策略详解

### 策略 A：Delta 中性套利（最常用）
```
目标：赚取 Funding Rate，不承担币价风险

操作：
  做多现货 BTC（1x）
  做空永续 BTC（1x）
  
收益来源：
  每 8h 收取 Funding Rate（当 rate > 0）
  
成本：
  现货手续费：0.1%（开仓）+ 0.1%（平仓）= 0.2%
  合约手续费：0.02%（开仓）+ 0.02%（平仓）= 0.04%
  基差风险：现货和合约价格偏离
  
净收益（示例）：
  年化 Funding 收入：9%
  年化成本：~0.24%（手续费）
  净收益：~8.76%
```

### 策略 B：跨交易所 Funding Rate 套利
```
目标：利用不同交易所费率差异

示例：
  Binance BTC perp funding = +0.01%
  Bybit BTC perp funding = +0.03%
  
操作：
  在 Binance 做多永续（支付 0.01%）
  在 Bybit 做空永续（收取 0.03%）
  净赚取：0.02% / 8h = ~22% 年化
  
风险：
  需要两个交易所有资金
  交易所对手风险
  转账延迟（通常 10-30 分钟）
```

### 策略 C：Funding Rate 均值回归
```
目标：预测 funding rate 变化，提前布局

逻辑：
  当 funding rate 连续 3 次 > 0.03%（极高）：
    → 预期套利者会进场，压低 funding rate
    → 做多永续（预期 funding rate 下降，价格收敛）
  
当 funding rate 连续 3 次 < -0.01%（极低）：
    → 预期多头会进场，推高 funding rate
    → 做空永续
```

## 5. 费率预测模型

### 特征工程
```python
# funding_rate_prediction_features.py
import numpy as np

def extract_funding_features(symbol, lookback=72):
    """
    提取 funding rate 预测特征
    lookback: 回溯小时数（默认 72h = 9 次结算）
    """
    # 1. 历史 funding rate 序列
    rates = fetch_funding_rates(symbol, limit=lookback//8)
    
    features = {}
    
    # 特征 1：移动平均
    features['ma_3'] = np.mean(rates[-3:])  # 近 3 次平均
    features['ma_9'] = np.mean(rates[-9:])  # 近 9 次平均
    
    # 特征 2：溢价指数（永续价格 - 现货价格）/ 现货价格
    perp_price = fetch_price(symbol + 'PERP')
    spot_price = fetch_price(symbol)
    features['premium'] = (perp_price - spot_price) / spot_price
    
    # 特征 3：未平仓合约（Open Interest）变化
    oi_current = fetch_open_interest(symbol)
    oi_24h_ago = fetch_open_interest(symbol, hours_ago=24)
    features['oi_change_24h'] = (oi_current - oi_24h_ago) / oi_24h_ago
    
    # 特征 4：现货价格动量
    spot_24h = fetch_price(symbol, hours_ago=24)
    features['spot_momentum'] = (spot_price - spot_24h) / spot_24h
    
    # 特征 5：波动率（近 24h）
    candles = fetch_klines(symbol, interval='1h', limit=24)
    closes = [c['close'] for c in candles]
    features['volatility_24h'] = np.std(np.diff(np.log(closes)))
    
    return features
```

### 简单预测模型（逻辑回归）
```python
# funding_rate_predictor.py
from indicators import calc_logistic_regression  # 自建
import numpy as np

def predict_next_funding(features):
    """
    预测下一次 funding rate 方向（涨/跌）
    返回：{'direction': 'UP'/'DOWN', 'confidence': 0.0-1.0}
    """
    # 权重（通过历史数据训练得到，此处为示例）
    weights = {
        'premium': 0.6,         # 溢价是最强信号
        'oi_change_24h': 0.2,   # OI 增加 → funding 上升
        'spot_momentum': 0.15,   # 价格上涨 → funding 上升
        'volatility_24h': 0.05,  # 高波动 → funding 上升
    }
    
    score = 0.0
    for k, w in weights.items():
        if k in features:
            score += features[k] * w
    
    if score > 0.01:
        return {'direction': 'UP', 'confidence': min(score * 10, 1.0)}
    elif score < -0.01:
        return {'direction': 'DOWN', 'confidence': min(abs(score) * 10, 1.0)}
    else:
        return {'direction': 'FLAT', 'confidence': 0.5}
```

## 6. 实战风险管理

### 风险 1：基差风险
```
问题：现货和合约价格偏离，Delta 中性被打破

示例：
  做多现货 BTC @ $100,000
  做空永续 BTC @ $100,100（溢价 0.1%）
  
  如果现货跌 10%，永续跌 10.5%（基差扩大）：
    现货亏损：$10,000
    合约盈利：$10,500
    净盈利：$500（基差扩大赚）
    
  但如果基差收敛（现货跌 10%，永续跌 9.5%）：
    现货亏损：$10,000
    合约盈利：$9,500
    净亏损：$500（基差收敛亏）
```

**缓解方法**：
- 选择流动性好的大币种（BTC/ETH），基差通常 < 0.2%
- 设置基差监控警报（基差 > 0.5% 时平仓）

### 风险 2：Funding Rate 反转
```
问题：做空永续赚取 funding rate，但市场转熊，funding rate 变负

示例（2022 年熊市）：
  2022.01: BTC funding rate = +0.02%（做空永续赚）
  2022.06: BTC funding rate = -0.01%（做空永续亏）
  
  如果没及时平仓，半年亏损 = -0.01% * 180 / 8 * 3 ≈ -6.75%
```

**缓解方法**：
- 监控 funding rate 7 日移动平均，低于 0.005% 时平仓
- 设置动态止损：连续 3 次 funding rate 为负时退出

### 风险 3：交易所对手风险
```
问题：交易所暴雷（如 FTX），资金无法取出

示例：
  FTX 暴雷前，很多用户在 FTX 做 funding rate 套利
  暴雷后，资金无法取出，损失 100%
```

**缓解方法**：
- 单一交易所资金不超过总资金的 30%
- 优先选择 Binance（流动性最好，风险最低）
- 定期检查交易所储备金证明（Proof of Reserves）

### 模板 2：Delta 中性套利回测
```python
# backtest_funding_arb.py
import sys
sys.path.insert(0, 'scripts')

from data_fetch import fetch_funding_rates, fetch_klines
from datetime import datetime, timedelta

def backtest_funding_arb(symbol, start_date, end_date, capital=10000):
    """
    Delta 中性套利回测
    
    参数：
      symbol: 交易对（如 'BTCUSDT'）
      start_date: 开始日期（'2024-01-01'）
      end_date: 结束日期（'2024-12-31'）
      capital: 本金（USD）
    
    返回：回测结果字典
    """
    # 获取 funding rates
    rates = fetch_funding_rates(symbol, start=start_date, end=end_date)
    
    # 获取现货和合约价格（计算基差）
    spot_prices = fetch_klines(symbol, start=start_date, end=end_date, interval='1d')
    perp_prices = fetch_klines(symbol + 'PERP', start=start_date, end=end_date, interval='1d')
    
    total_funding_income = 0.0
    total_slippage_cost = 0.0
    total_fee_cost = 0.0
    daily_pnl = []
    
    for j, rate_info in enumerate(rates):
        rate = rate_info['rate']
        notional = capital  # 名义价值（1x 杠杆）
        
        # Funding income
        if rate > 0:
            # 做空永续，收取 funding
            funding_income = notional * rate
        else:
            # 做空永续，支付 funding
            funding_income = notional * rate  # rate 为负，收入为负的
        
        total_funding_income += funding_income
        
        # 基差成本（简化模型）
        if j < len(spot_prices) and j < len(perp_prices):
            spot = spot_prices[j]['close']
            perp = perp_prices[j]['close']
            basis = (perp - spot) / spot  # 基差
            # 基差扩大 → 亏损；基差收敛 → 盈利（简化）
            basis_pnl = capital * basis * 0.1  # 假设 10% 的基差影响
            total_slippage_cost += basis_pnl
        
        # 手续费（开仓 + 平仓，假设每月调仓一次）
        if j % 90 == 0:  # 每 90 次结算（约 30 天）
            fee = capital * 0.001 * 2  # 0.1% * 2
            total_fee_cost += fee
        
        daily_pnl.append(funding_income + basis_pnl - (fee if j % 90 == 0 else 0))
    
    net_profit = total_funding_income + total_slippage_cost - total_fee_cost
    annual_return = net_profit / capital * (365 / (len(rates) / 3))  # len(rates)/3 = 天数
    
    return {
        'total_funding_income': total_funding_income,
        'total_basis_cost': total_slippage_cost,
        'total_fee_cost': total_fee_cost,
        'net_profit': net_profit,
        'annual_return': annual_return * 100,  # 百分比
        'daily_pnl': daily_pnl,
        'sharpe': calculate_sharpe(daily_pnl),
    }

def calculate_sharpe(daily_pnl):
    import numpy as np
    returns = np.array(daily_pnl) / 10000  # 假设本金 10000
    if len(returns) < 2:
        return 0.0
    return np.mean(returns) / np.std(returns) * np.sqrt(252)

if __name__ == '__main__':
    result = backtest_funding_arb(
        symbol='BTCUSDT',
        start_date='2024-01-01',
        end_date='2024-12-31',
        capital=10000
    )
    
    print("=== Funding Rate 套利回测结果 ===")
    print(f"Funding 总收入: ${result['total_funding_income']:.2f}")
    print(f"基差成本: ${result['total_basis_cost']:.2f}")
    print(f"手续费成本: ${result['total_fee_cost']:.2f}")
    print(f"净利润: ${result['net_profit']:.2f}")
    print(f"年化收益: {result['annual_return']:.2f}%")
    print(f"夏普比率: {result['sharpe']:.2f}")
```

### 模板 3：实时监控 Funding Rate 并预警
```python
# monitor_funding.py
import sys
sys.path.insert(0, 'scripts')

from data_fetch import fetch_funding_rates
from alerts import send_alert
import time

def monitor_funding(symbol, threshold=0.02):
    """
    实时监控 funding rate，超过阈值发送警报
    
    参数：
      symbol: 交易对
      threshold: 阈值（%，如 0.02 表示 0.02%）
    """
    while True:
        rates = fetch_funding_rates(symbol, limit=1)
        current_rate = rates[0]['rate'] * 100  # 转成百分比
        
        if current_rate > threshold:
            msg = f"⚠️ {symbol} Funding Rate 过高: {current_rate:.4f}%"
            send_alert(msg)
            print(msg)
        
        elif current_rate < -threshold:
            msg = f"⚠️ {symbol} Funding Rate 过低: {current_rate:.4f}%"
            send_alert(msg)
            print(msg)
        
        # 每 1 小时检查一次
        time.sleep(3600)

if __name__ == '__main__':
    monitor_funding('BTCUSDT', threshold=0.02)
```

## 8. 进阶话题

### Funding Rate 与现货 ETF 的关系
```
当 BTC 现货 ETF 通过后（2024.01）：
  - 传统资金可以通过 ETF 做多 BTC
  - 永续合约的溢价降低（因为 ETF 分流了多头需求）
  - Funding Rate 长期均值下降
  
数据：
  2023 年 BTC 平均 funding rate（8h）：0.005%
  2024 年 BTC 平均 funding rate（8h）：0.008%（不降反升，因为牛市）
  预期 2025 年：0.003%（ETF 完全消化后）
```

### Funding Rate 作为市场情绪指标
```
Funding Rate 极度高水平（> 0.05%/8h）：
  → 市场过度看多，可能见顶
  → 策略：做空永续，或平仓离场

Funding Rate 极度负水平（< -0.03%/8h）：
  → 市场过度看空，可能见底
  → 策略：做多永续，或抄底现货
```

## 9. 总结与建议

### 适合做 Funding Rate 套利的场景
- ✅ 牛市中期（funding rate 稳定为正）
- ✅ 大币种（BTC/ETH），流动性好
- ✅ 有低成本现货渠道（如 Coinbase Prime）

### 不适合的场景
- ❌ 熊市（funding rate 经常为负）
- ❌ 小币种（流动性差，基差风险高）
- ❌ 高波动时期（如 LUNA 崩盘）

### 最佳实践
1. **永远做 Delta 中性**：不要裸空永续，要同时做多现货
2. **分散交易所**：不要 all-in 一个交易所
3. **监控基差**：基差 > 0.5% 时警惕
4. **定期调仓**：每周检查一次 funding rate 趋势，必要时平仓
