## 一、什么是叙事（Narrative）？

**定义**：市场中广泛传播的故事/主题，能驱动资金流向和币价涨跌。

**例子**：
- 2023年初：AI Agent 叙事（FET、AGIX 暴涨 500%+）
- 2023年中：RWA 叙事（ONDO 上线后涨 300%+）
- 2024年初：BTC ETF 叙事（BTC 破 $70,000）

## 五、叙事生命周期与操作策略

### 5.1 生命周期阶段

```
引入期 → 升温期 → 狂热期 → 降温期 → 退潮期
  ↑           ↑           ↑           ↑           ↑
  早鸟入      追涨        顶峰        获利了结    放弃
```

### 5.2 操作建议

| 阶段 | 叙事热度 | 操作 | 仓位 |
|------|---------|------|------|
| 引入期 | 20-40 | 小仓位试错 | 5-10% |
| 升温期 | 40-70 | 加仓至目标仓位 | 20-30% |
| 狂热期 | 70-90 | 开始减仓 | 10-20% |
| 降温期 | 40-70 | 清仓 | 0% |
| 退潮期 | <40 | 等待下一叙事 | 0% |

## 八、风险提示

1. **叙事不等于币价**：热度高的叙事不一定涨（可能是"利好出尽"）
2. **避免追高**：叙事排名前2时，谨慎追高（已过热）
3. **结合技术分析**：叙事 + 技术指标 + 风控 = 完整交易系统
4. **虚假叙事**：警惕"拉盘叙事"，验证项目基本面

## 十、故障排除

### 问题1：数据源 API 限流

**现象**：`Rate limit exceeded` 错误

**解决**：
1. 申请 CryptoPanic API Key（免费版 10 req/min）
2. 使用 `--cache` 参数缓存结果（避免重复请求）
3. 降低扫描频率（`--interval 7200` = 每2小时）

### 问题2：叙事-代币映射错误

**现象**：叙事关联了错误的代币

**解决**：
1. 手动编辑 `narrative_tracker.py` 中的 `NARRATIVE_TOKEN_MAP`
2. 提交 PR 到 GitHub 仓库

### 问题3：热度评分异常

**现象**：叙事热度突然飙升至 100

**解决**：
1. 检查是否有重大事件（上所、空投宣布）
2. 使用 `--smooth` 参数平滑异常值
