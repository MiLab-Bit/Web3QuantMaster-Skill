## 1. 订单簿（Order Book）分析

### 基础概念
```
买单簿（Bids）：按价格从高到低排列
卖单簿（Asks）：按价格从低到高排列

Best Bid（买一价）：买单簿最高价
Best Ask（卖一价）：卖单簿最低价
Spread（价差）：Ask1 - Bid1
```

### 关键指标
| 指标 | 公式 | 说明 |
|------|------|------|
| **Bid-Ask Spread** | Ask1 - Bid1 | 越小流动性越好 |
| **Mid Price** | (Bid1 + Ask1) / 2 | 中间价 |
| **Book Depth** | 前 10 档总量（USD） | 深度越大，冲击越小 |
| **Walk-through Cost** | 吃单 $10,000 的平均价 | 实际滑点 |

### 订单簿快照示例（Binance BTC/USDT）
```
Bid（买）                    Ask（卖）
价格       量(USD)              价格       量(USD)
$99,950    $125,000            $99,951   $98,000
$99,949    $87,000             $99,952   $112,000
$99,948    $203,000            $99,953   $76,000
$99,947    $54,000             $99,954   $143,000
...
```
**Spread**: $0.001 (0.00001%)
**Mid Price**: $99,950.5
**Depth（前 5 档）**: Bid $584,000 + Ask $529,000 = $1,113,000

### 代码模板：获取订单簿
```python
# fetch_order_book.py
import ccxt
import pandas as pd

def fetch_order_book(exchange_id, symbol, limit=20):
    """
    获取订单簿（Order Book）
    """
    exchange = getattr(ccxt, exchange_id)({
        'enableRateLimit': True,
    })
    
    ob = exchange.fetch_order_book(symbol, limit=limit)
    
    bids = pd.DataFrame(ob['bids'], columns=['price', 'amount'])
    asks = pd.DataFrame(ob['asks'], columns=['price', 'amount'])
    
    # 计算指标
    best_bid = bids.iloc[0]['price']
    best_ask = asks.iloc[0]['price']
    spread = best_ask - best_bid
    mid_price = (best_bid + best_ask) / 2
    spread_pct = spread / mid_price * 100
    
    # 深度（前 10 档）
    bid_depth = (bids.iloc[:10]['price'] * bids.iloc[:10]['amount']).sum()
    ask_depth = (asks.iloc[:10]['price'] * asks.iloc[:10]['amount']).sum()
    
    return {
        'best_bid': best_bid,
        'best_ask': best_ask,
        'spread': spread,
        'spread_pct': spread_pct,
        'mid_price': mid_price,
        'bid_depth_usd': bid_depth,
        'ask_depth_usd': ask_depth,
        'bids': bids,
        'asks': asks,
    }

# 使用
if __name__ == '__main__':
    ob = fetch_order_book('binance', 'BTC/USDT', limit=20)
    
    print(f"Best Bid: ${ob['best_bid']:,.2f}")
    print(f"Best Ask: ${ob['best_ask']:,.2f}")
    print(f"Spread: ${ob['spread']:.2f} ({ob['spread_pct']:.4f}%)")
    print(f"Bid Depth (Top 10): ${ob['bid_depth_usd']:,.0f}")
    print(f"Ask Depth (Top 10): ${ob['ask_depth_usd']:,.0f}")
```

## 2. 滑点（Slippage）模型

### 什么是滑点？
```
预期价格：$100,000
实际成交价格：$99,980（买单）
滑点 = ($100,000 - $99,980) / $100,000 = 0.02%
```

### 滑点影响因素
1. **订单规模**：越大滑点越大
2. **市场波动性**：波动率越高滑点越大
3. **订单簿深度**：深度越深滑点越小
4. **市场状态**：开盘/收盘时滑点更大

### 滑点模型（四种）

#### 模型 A：线性模型（最简单）
```python
def linear_slippage(order_size_usd, avg_depth_per_dollar):
    """
    线性滑点模型
    
    参数：
      order_size_usd: 订单金额（USD）
      avg_depth_per_dollar: 每美元对应的订单簿深度
    """
    slippage_pct = order_size_usd / avg_depth_per_dollar * 0.0001
    return min(slippage_pct, 0.01)  # 上限 1%
```

#### 模型 B：平方根模型（常用）
```python
def sqrt_slippage(order_size_usd, volatility, depth_factor=10000):
    """
    平方根滑点模型（类似 Almgren-Chriss）
    
    参数：
      order_size_usd: 订单金额（USD）
      volatility: 年化波动率（如 0.6 表示 60%）
      depth_factor: 深度因子（根据历史数据校准）
    """
    import numpy as np
    slippage = volatility * np.sqrt(order_size_usd / depth_factor)
    return min(slippage, 0.02)  # 上限 2%
```

#### 模型 C：基于订单簿的精确计算
```python
def order_book_slippage(order_book, order_size_coin, side='buy'):
    """
    根据订单簿计算精确滑点
    
    参数：
      order_book: fetch_order_book 返回的订单簿
      order_size_coin: 订单数量（币）
      side: 'buy' 或 'sell'
    """
    if side == 'buy':
        book = order_book['asks']  # 吃卖单
    else:
        book = order_book['bids']  # 吃买单
    
    remaining = order_size_coin
    total_cost = 0.0
    
    for _, row in book.iterrows():
        price = row['price']
        amount = row['amount']
        
        if remaining <= amount:
            total_cost += remaining * price
            break
        else:
            total_cost += amount * price
            remaining -= amount
    
    if remaining > 0:
        # 订单簿深度不足
        return None  # 无法完全成交
    
    avg_price = total_cost / order_size_coin
    expected_price = order_book['mid_price']
    
    slippage_pct = (avg_price - expected_price) / expected_price if side == 'buy' else (expected_price - avg_price) / expected_price
    
    return slippage_pct
```

```python
def train_slippage_model(historical_trades, order_book_features):

    """预测滑点"""
    features = np.array([[ 
        order_size_usd / 10000,
        volatility,
        spread,
        depth / 1000000,
        time_of_day,
    ]])
    
    return model.predict(features)[0]
```

## 4. 市场冲击（Market Impact）

### 定义
```
市场冲击 = 大额订单对价格的永久性影响
临时冲击：订单执行期间的价格偏移（滑点）
永久冲击：订单执行后，价格永久性移动
```

### 市场冲击模型（Almgren-Chriss）
```python
def market_impact(order_size_usd, daily_volume, volatility, theta=0.5):
    """
    市场冲击模型
    
    参数：
      order_size_usd: 订单金额（USD）
      daily_volume: 日均交易量（USD）
      volatility: 年化波动率
      theta: 永久冲击比例（0-1）
    """
    # 参与率
    participation_rate = order_size_usd / daily_volume
    
    # 临时冲击（滑点）
    temporary_impact = volatility * np.sqrt(participation_rate)
    
    # 永久冲击
    permanent_impact = theta * volatility * participation_rate
    
    total_impact = temporary_impact + permanent_impact
    
    return {
        'temporary_impact_pct': temporary_impact,
        'permanent_impact_pct': permanent_impact,
        'total_impact_pct': total_impact,
    }
```

### 降低市场冲击的方法
1. **拆分订单**：将 $100,000 订单拆成 10 个 $10,000 订单
2. **使用限价单**：避免市价单的冲击
3. **选择低波动时段**：美股收盘后（21:00-23:00 UTC）波动率低
4. **使用暗池（Dark Pool）**：不公开订单（仅机构）

## 5. 执行算法（Execution Algorithms）

### 算法 1：TWAP（Time-Weighted Average Price）
```
目标：在固定时间内均匀执行订单，使成交均价接近 TWAP
适用：流动性好的大币（BTC、ETH）
```

#### 代码模板
```python
# twap_execution.py
import time
from datetime import datetime, timedelta

def twap_execution(symbol, total_amount_coin, duration_minutes, exchange):
    """
    TWAP 执行算法
    
    参数：
      symbol: 交易对
      total_amount_coin: 总订单量（币）
      duration_minutes: 执行时长（分钟）
      exchange: ccxt 交易所对象
    """
    num_slices = duration_minutes  # 每分钟执行一次
    slice_amount = total_amount_coin / num_slices
    
    print(f"TWAP 开始: {datetime.now()}")
    print(f"  总量: {total_amount_coin} {symbol}")
    print(f"  时长: {duration_minutes} 分钟")
    print(f"  每片: {slice_amount:.4f} {symbol}")
    
    for i in range(num_slices):
        try:
            # 下单
            order = exchange.create_market_buy_order(
                symbol=symbol,
                amount=slice_amount
            )
            print(f"  [{i+1}/{num_slices}] 成交: {order['filled']} @ ${order['average']:,.2f}")
            
            # 等待 1 分钟
            if i < num_slices - 1:
                time.sleep(60)
        
        except Exception as e:
            print(f"  错误: {e}")
            time.sleep(60)
    
    print(f"TWAP 完成: {datetime.now()}")

# 使用
if __name__ == '__main__':
    exchange = ccxt.binance({'apiKey': '...', 'secret': '...'})
    twap_execution('BTC/USDT', total_amount_coin=1.0, duration_minutes=30, exchange=exchange)
```

### 算法 2：VWAP（Volume-Weighted Average Price）
```
目标：根据交易量分布执行订单，使成交均价接近 VWAP
适用：知道交易量时间分布的场景
```

#### 代码模板
```python
# vwap_execution.py
def vwap_execution(symbol, total_amount_coin, exchange):
    """
    VWAP 执行算法
    
    根据历史交易量分布调整每片订单量
    通常：开盘和收盘时段交易量更大
    """
    # 获取历史交易量分布（简化：假设正态分布）
    # 实际应该从交易所获取历史数据
    volume_profile = [
        0.08, 0.06, 0.05, 0.04, 0.04, 0.05, 0.06, 0.08,  # 开盘 8 小时
        0.04, 0.03, 0.03, 0.03, 0.03, 0.03, 0.04, 0.05,  # 盘中 8 小时
        0.06, 0.08, 0.10, 0.12, 0.10, 0.08,  # 收盘 6 小时
    ]
    
    total_profile = sum(volume_profile)
    normalized_profile = [v / total_profile for v in volume_profile]
    
    # 执行
    for i, profile in enumerate(normalized_profile):
        slice_amount = total_amount_coin * profile
        
        try:
            order = exchange.create_market_buy_order(
                symbol=symbol,
                amount=slice_amount
            )
            print(f"  [{i+1}] 成交: {order['filled']} @ ${order['average']:,.2f}")
            
            # 等待 1 小时
            if i < len(normalized_profile) - 1:
                time.sleep(3600)
        
        except Exception as e:
            print(f"  错误: {e}")
            time.sleep(3600)
```

### 算法 3：POV（Percentage of Volume）
```
目标：以固定参与率（如 10%）执行订单
适用：需要隐藏订单规模的机构
```

#### 代码模板
```python
# pov_execution.py
def pov_execution(symbol, total_amount_coin, participation_rate=0.1, exchange):
    """
    POV 执行算法
    
    参数：
      participation_rate: 参与率（如 0.1 表示 10%）
    """
    remaining = total_amount_coin
    
    while remaining > 0:
        # 获取过去 1 分钟交易量
        trades = exchange.fetch_trades(symbol, limit=100)
        volume_1m = sum([t['amount'] for t in trades]) / 60  # 每分钟
        
        # 计算本片订单量
        slice_amount = volume_1m * participation_rate
        slice_amount = min(slice_amount, remaining)
        
        if slice_amount > 0:
            try:
                order = exchange.create_market_buy_order(
                    symbol=symbol,
                    amount=slice_amount
                )
                remaining -= order['filled']
                print(f"  剩余: {remaining:.4f} {symbol}")
            except Exception as e:
                print(f"  错误: {e}")
        
        time.sleep(60)
```

## 6. Web3 独有：DEX 流动性分析

### DEX vs CEX 流动性对比
| 维度 | CEX（Binance） | DEX（Uniswap） |
|------|-----------------|------------------|
| **流动性来源** | 订单簿 | AMM 池（x × y = k） |
| **滑点模型** | 订单簿深度 | AMM 公式（Δy = Δx * y / (x + Δx)） |
| **Gas 费** | 无 | 有（以太坊 ~$10-50） |
| **MEV 风险** | 低 | 高（三明治攻击） |

### AMM 滑点计算（Uniswap V2）
```python
def amm_slippage(reserve_in, reserve_out, amount_in):
    """
    AMM 滑点计算（Uniswap V2 公式）
    
    公式：
      amount_out = reserve_out * amount_in / (reserve_in + amount_in)
      滑点 = (预期价格 - 实际价格) / 预期价格
    """
    # 预期价格（无滑点）
    expected_price = reserve_out / reserve_in
    
    # 实际成交量
    amount_out = (reserve_out * amount_in) / (reserve_in + amount_in)
    
    # 实际价格
    actual_price = amount_out / amount_in
    
    # 滑点
    slippage_pct = (expected_price - actual_price) / expected_price
    
    return {
        'expected_price': expected_price,
        'actual_price': actual_price,
        'amount_out': amount_out,
        'slippage_pct': slippage_pct,
    }

# 示例
if __name__ == '__main__':
    # ETH/USDC 池：储备 1,000 ETH 和 3,000,000 USDC

    reserve_usdc = 3_000_000
    
    # 买入 10 ETH
    amount_in_usdc = 30000  # $30,000
    
    result = amm_slippage(reserve_usdc, reserve_eth, amount_in_usdc)
    
    print(f"预期价格: ${result['expected_price']:,.2f}")
    print(f"实际价格: ${result['actual_price']:,.2f}")
    print(f"滑点: {result['slippage_pct']*100:.2f}%")
    print(f"获得 ETH: {result['amount_out']:.4f}")
```

## 7. Web3 独有：MEV 与三明治攻击

### 什么是 MEV（Maximal Extractable Value）？
```
矿工/验证者通过重新排序交易，提取额外利润

常见攻击：
  1. 三明治攻击（Sandwich Attack）
  2. 抢跑（Front-running）
  3. 尾随（Back-running）
```

### 三明治攻击原理
```
受害者：买入 10 ETH @ $3,000
攻击者：
  1. 抢跑：在受害者前买入 10 ETH（推高价格到 $3,005）
  2. 受害者成交 @ $3,005（滑点）
  3. 攻击者卖出 10 ETH @ $3,004（获利 $10/ETH）
```

### 防护方法
| 方法 | 说明 | 效果 |
|------|------|------|
| **设置高 Gas** | 让攻击者成本增加 | 中等 |
| **使用私有 RPC** | 如 Flashbots Protect | ⭐⭐⭐⭐⭐（最好） |

```python
# smart_order_routing.py
def smart_order_routing(symbol, amount_coin, exchanges=['binance', 'bybit', 'okx']):
    """
    智能订单路由：在多个交易所中寻找最佳流动性
    
    策略：
      1. 获取所有交易所的订单簿
      2. 计算各交易所的滑点
      3. 将订单拆分到滑点最小的交易所
    """
    best_exchange = None
    best_slippage = float('inf')
    
    for ex in exchanges:
        try:
            exchange = getattr(ccxt, ex)()
            ob = fetch_order_book(ex, symbol, limit=20)
            
            slippage = order_book_slippage(ob, amount_coin, side='buy')
            
            if slippage and slippage < best_slippage:
                best_slippage = slippage
                best_exchange = ex
        
        except Exception as e:
            print(f"  {ex} 获取失败: {e}")
    
    print(f"最佳交易所: {best_exchange}")
    print(f"  滑点: {best_slippage*100:.3f}%")
    
    return best_exchange, best_slippage
```
