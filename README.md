## 这是什么

Web3QuantMaster 是一个**只读的加密货币量化分析助手**：你用大白话提问，它调用一整套分析引擎，把市场、因子、风险、组合、链上的结论整理好交给你。它帮你「想清楚」，但**不下单、不荐股**。

## 六大能力

**1. 策略回测**
选一个策略（如均线交叉、通道突破），填上币种和周期，立刻看到它在历史上的表现：赚了多少、最大回撤、夏普/索提诺比率，以及多空双向、滑点、手续费都按真实成本算。

**2. 因子分析**
不用手调几十个指标。它自动生成几百个候选因子，再用 IC 等统计方法筛出真正有信息量的那批，告诉你哪个维度（趋势/动量/波动/量价）在哪个币种上更有效。

**3. 风控体检**
- 算 VaR / CVaR（三种方法），告诉你「正常日子里最坏可能亏多少」；
- 一键跑历史黑天鹅场景（Luna 崩盘、FTX 危机、312 暴跌等），看你的仓位扛不扛得住；
- 下单前自动五重检查（仓位/集中度/滑点/杠杆/最小订单），并监控总亏损、单日亏损、连续亏损。

**4. 组合配置**
把 BTC、ETH、SOL 等一起回测，给出分散化效果、各资产贡献度，以及更稳的权重分配（均值-方差前沿 / 风险平价 / Black-Litterman）。

**5. 链上透视**
- 资金费率套利：三家交易所横向比价，算年化收益与风险等级；
- 无常损失：给定币价变动，估算做 LP 相比直接持有亏多少；
- 交易解码：任意链上交易一键看懂；
- 余额与持有人分布、合约安全审计、三明治攻击监测、代币解锁冲击分析。

**6. 实时预警**
价格触及阈值、市场叙事异动时主动提醒，把分析从「你来问」变成「它来叫你」。

## 怎么开始

```bash
pip install -e .          # 装核心依赖
python main.py --help     # 看全部命令

python main.py strategy-list              # 有哪些策略可回测
python main.py run-backtest --symbol BTCUSDT --strategy ma_cross
python main.py factor-analysis --symbol ETHUSDT
python main.py risk-assessment --symbol BTCUSDT
```

不想敲命令，也可以把它作为 **MCP 工具**接进支持 MCP 的客户端（见下）。
